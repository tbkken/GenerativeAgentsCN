# 第二章核查与验证记录

记录日期：**2026-09-25**。本文件说明书稿与教学示例的实际验证范围，不是模型能力排行榜，也不是 WorkBuddy 或 GenerativeAgentsCN 的运行验收报告。

## 已完成的检查

| 项目 | 方法与结果 |
| --- | --- |
| 正文结构 | 14 节正文，约 3 万汉字；逐节检查概念、API 路线、WorkBuddy 路线、验证与失败练习 |
| 教学数据 | 核对日期、时区、人数、时长、允许房间和半开时间区间的一致性 |

35 项测试包括 32 项标准库测试、2 项 OpenAI SDK 模拟 HTTP 测试和 1 项 MCP 进程内集成测试。覆盖范围包括容量与预约冲突、时间边界、未知/重复 ID、JSON 非有限数、CLI 退出码、工具调用预算、无进展停止、拒绝与中断、检索排序、多角色审阅输入与失败交付边界。

MockTransport 测试期间，SDK 的日志可能出现 `POST https://api.openai.com/v1/responses` 和模拟的 `200 OK`；这些请求由内存中的假传输处理，没有发往 OpenAI 服务。它们不产生真实模型结果。

## 如何复查

按[示例安装说明](examples/README.md)安装两份 requirements 后，在 `examples` 目录运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
```

未安装可选依赖时，相应测试会显示 `skipped`。标准库部分仍可运行，但“跳过”不能写成“全部验证通过”。本次写作使用的 MCP 依赖位于临时目录，未修改主项目依赖。

复查排期时，人工 fixture 与确定性基线可能选择不同的合法时段：手作活动可以安排 09:00—10:00，也可以安排 10:30—11:30。以业务条件判断，不把某个唯一答案文本当成全部正确解。
