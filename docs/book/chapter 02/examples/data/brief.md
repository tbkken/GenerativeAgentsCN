# 青禾社区学习中心开放日筹备需求

本练习中的机构、人员和活动均为虚构。只制作排期草案，不联系人员、不发送通知、不建立真实预约。

## 目标

为 2026-10-17（Asia/Shanghai）09:00–12:00 的开放日安排阅读分享、手作体验和邻里交流。交付 `schedule.json`、独立校验的 `validation-report.json` 和给工作人员阅读的 `plan.md`。可额外把材料约束提取为 `constraints.json`，但它不能覆盖原始材料。

## 事实来源

房间容量以 `rooms.csv` 为准；活动人数、时长、可用窗口和允许房间以 `requests.csv` 为准；已有预约以 `availability.json` 为准；业务规则以 `rules.md` 为准。材料缺失或矛盾时列出待确认项，不自行补事实。示意图只帮助理解布局。

## 交付内容

每项活动必须有活动 ID、房间 ID、带日期和时区偏移的开始/结束时间、人数。说明每项选择依据、预约冲突检查结果及尚未完成的事项。通过程序检查仅表示满足这份教学材料中的规则，不代表现实活动已经获批。
