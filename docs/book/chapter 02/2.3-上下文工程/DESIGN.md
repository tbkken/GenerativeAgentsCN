### 5.1 绘制规范

- **箭头**：文字符号 `›`／`↓`，**必须包进固定宽 44px 的 Box 再计入总宽**（`›` 实测约 32px）。
- **节点框**：圆角 8–10px，浅底色；节点内标签 14–15px，节点标题 19–22px bold。
- **分组容器**：圆角 12px，底色 `#F4F7FA`，内间距 ≥ 18px。
- **对照表重绘成条目时**，每行必须有左侧色标（4×54px），不用横线画表格。
- **固定宽拼接的精确对齐图形（时间条、状态条、代码行）不写 `border`**：描边会被额外计入宽度导致溢出。改用实心色块区分状态（橙底白字／浅橙底橙字／浅绿底绿字）。
- **代码块**：整块底色 `#EDF4FC` 或 `#F4F7FA`，圆角 10px，等宽字体 13–14px，行高 1.7；关键字与注释用 `#546779`，字符串用 `#26816B`，函数名用 `#276FBF`。**一律 Box + Text 排版，禁止截图。**
- **禁止 emoji，也禁止使用图标组件（Font Awesome 等）**：图标在导出后会变成嵌入图片，破坏「全部元素可编辑」的硬要求。需要图形语义时，用原生圆角色块 + 单字。
- **连接线**：链接箭头用文字符号配合颜色，不用图片。

### 5.2 禁止项

- 禁止用位图或图表截图代替可编辑结构。
- 禁止使用图标组件与 emoji。
- 禁止把书稿 `figures/` 下的任何 png／svg 引入页面（包括 `03-context-packing.png`、`03-conversation-state.png`、`03-fact-refresh.png`）。
- 禁止把 2.3 的三张 mermaid 图直接渲染后贴入；只取语义重绘。

## 7. 讲稿备注（speaker notes）规范

- **每页必须有 `notes`**，是教师当页要读给学生听的自然逐字稿。
- 长度 120–300 字；第一人称直接讲观点，补充页面未展开的背景、原理或例子。
- 严禁元描述：「这一页展示了／本页聚焦于／下图描述了／上一步／这张表／接下来我们进入」。
- 分点逻辑必须换行分段。
- 备注内容必须能在书稿正文找到依据，不得杜撰数值或结论。
- **写入方式**：页面源文件写 `notes` 后运行注入脚本：
  `python .workbuddy/tools/add_pptx_notes.py "<slides 目录>" "<pptx 路径>"`
