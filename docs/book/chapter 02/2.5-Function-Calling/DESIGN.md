### 5.1 绘制规范

- **箭头**：`›`／`↓` 文字符号，颜色跟随前一段链路。**文字箭头 `›` 实测约 32px 宽，必须包进固定宽度 44px 的 Box 再计入一行总宽**。
- **节点框**：圆角 8px，浅底色；节点内标签 14px，节点标题 19–22px bold。
- **分组容器**：圆角 12px，底色 `#F4F7FA`，内间距 ≥ 20px。
- **对照表重绘成条目时**，每行必须有左侧色标（3–4×40px），不用横线画表格。
- **固定宽度拼接的图形（六步链路、三分支分流）不写 `border`**：描边会被额外计入宽度导致溢出。改用实心色块区分状态（蓝底蓝字／绿底绿字／橙底橙字）。
- **等宽重绘**：JSON、Python、PowerShell、指令原文一律放进 `#F4F7FA` 圆角容器，`fontFamily: Consolas, monospace`，行内含 `{ }` 时整行写成 JS 字符串字面量（`{'...'}`）以避开 JSX 表达式解析。
- **禁止 emoji，也禁止使用图标组件（Font Awesome 等）**：图标在导出后会变成嵌入图片，破坏「全部元素可编辑」的硬要求。需要图形语义时，用原生圆角色块 + 单字（如 求／执／判／停）。
- **禁止把书稿 `figures/` 下的任何 png／svg 引入页面**（包括 `05-function-sequence.png`、`05-function-correlation.png`、`05-function-failure.png`）。

## 7. 讲稿备注（speaker notes）规范

- **每页必须有 `notes`**，是教师当页要读给学生听的自然逐字稿。
- 长度 120–300 字；第一人称直接讲观点，补充页面未展开的背景、原理或例子。
- 严禁元描述：「这一页展示了／本页聚焦于／下图描述了／上一步／这张表／接下来我们进入」。
- 分点逻辑必须换行分段。
- 备注内容必须能在书稿正文找到依据，不得杜撰数值或结论。
- **写入方式**：页面源文件写 `notes` 后运行注入脚本：
  `python .workbuddy/tools/add_pptx_notes.py "<slides 目录>" "<pptx 路径>"`
