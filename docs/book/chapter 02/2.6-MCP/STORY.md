## 二、页面骨架

### 2.1 叙事主线

一句话主线：**MCP 统一的是连接方式，不是业务判断。**

四个递进问题贯穿全篇：

1. **谁在连接谁**——宿主、客户端、服务端分别承担什么职责，服务端能表达哪三类能力（2.6.1）
2. **两条路线各管哪一段**——Function Calling 管一次请求的往返，MCP 管连接与发现；连接可以走本机标准流或远程 HTTP（2.6.2 + 2.6.3）
3. **接上之后怎么验收**——先看清业务合同，再启动服务、配好宿主，按顺序核对并留下证据（2.6.4 + 2.6.6）
4. **远程工具的三个独立检查**——工具范围、审批、服务身份分别核对，再用停用练习检验（2.6.5 + 2.6.7）
