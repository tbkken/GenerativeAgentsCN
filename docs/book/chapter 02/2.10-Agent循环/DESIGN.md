### 5.1 绘制规范

- **箭头**：2px 线段 + `›`／`↓` 文字符号组合；横向箭头长 ≥ 28px，纵向箭头长 ≥ 24px。**`›` 实测约 32px 宽，必须包进固定宽 44px 的 Box 再计入总宽。**
- **节点框**：圆角 8px，1px `#B5C7D8` 描边，浅底色；节点内标签 14px，节点标题 20–22px bold。
- **分组容器**：圆角 12px，底色 `#F4F7FA`，内间距 ≥ 20px。
- **对照表重绘成条目时**，每行必须有左侧色标（4×40px），不用横线画表格。
- **固定宽拼接的图形（闭环链条、五步链、三分支、记忆三源）一律不写 border**，改用实心色块区分状态（蓝底白字／浅蓝底蓝字／浅绿底绿字／浅橙底橙字），避免描边计入宽度导致溢出。
- **伪代码／代码标识**：用 `Consolas, monospace` 的 Text 直接排在浅底 Box 内（05 页的 `validate_schedule`、06 页的 `validate_schedule(schedule.json)`），禁止截图。
- **A 区标题块**：左侧竖标 4×44px 蓝 `#276FBF`，上排 14px `#546779` 小节号，下排 34px bold 主标题；扉页与封面不套用 A 区。
- **禁止 emoji，也禁止使用图标组件（Font Awesome 等）**：图标在导出后会变成嵌入图片，破坏「全部元素可编辑」的硬要求。需要图形语义时，用原生圆角色块 + 单字（如 观／决／执／验）。
- **连接线**：链接箭头用文字符号（`›`／`↓`）配合颜色，不用图片。

### 5.2 禁止项

- 禁止用位图或图表截图代替可编辑结构。
- 禁止使用图标组件与 emoji。
- 禁止把书稿 `figures/` 下的任何 png／svg 引入页面（包括 `agent-loop.png`、`10-loop-stop.png`、`10-memory-layers.png`）。
- 禁止把 2.10 的三张 mermaid 图直接渲染后贴入。

## 7. 讲稿备注（speaker notes）规范

- **每页必须有 `notes`**，是教师当页要读给学生听的自然逐字稿。
- 长度 120–300 字；第一人称直接讲观点，补充页面未展开的背景、原理或例子。
- 严禁元描述：「这一页展示了／本页聚焦于／下图描述了／上一步／这张表／接下来我们进入」。
- 分点逻辑必须换行分段。
- 备注内容必须能在书稿正文找到依据，不得杜撰数值或结论。
- **写入方式**：页面源文件写 `notes` 后运行注入脚本：
  `python .workbuddy/tools/add_pptx_notes.py "<slides 目录>" "<pptx 路径>"`
