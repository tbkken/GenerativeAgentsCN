## 二、页面骨架

### 2.1 叙事主线

一句话主线：**一次回答靠的是生成，一段闭环靠的是核验。**

四个递进问题贯穿全篇：

1. **怎么转起来**——观察、决定、执行、核验，谁承接哪一步（2.10.1）
2. **凭什么更聪明**——规划、ReAct、反思各增加什么，什么时候值得用循环（2.10.2）
3. **什么时候停**——把完成条件与停止条件写进程序，并分别计数（2.10.3）
4. **什么算「记得」**——三种记忆的边界，以及动手体验时的核对动作（2.10.4—2.10.6）

### 2.3 Hero 定位

Hero 页 7 张（24 页的 29%，落在 20–30% 区间）：

- **01 封面**——全幅闭环视觉，带回流箭头与橙色「核验」锚点
- **04 一轮闭环**——全篇结构主轴，四节点 + 回到观察的回流线
- **08 规划：拆成可检查的子目标**——五步分解链，计划可被事实修正
- **12 成功、继续与有原因地停止**——三分支判定，橙色停止口
- **18 三种「记住」不能混在一起**——三源汇入核验闸门
- **21 WorkBuddy 三种任务模式**——Ask / Plan / Agent 三种入口
- **24 结束页**——三句反问收束
