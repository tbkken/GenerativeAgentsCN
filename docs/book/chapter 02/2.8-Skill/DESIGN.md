### 5.1 绘制规范

- **箭头**：文字符号 `›`／`↓`；`›` 必须包进固定宽 **44px** 的 Box 再计入总宽；横向节点链 3 节点 × 340px + 2 × 44px = 1108px ≤ 1152px。
- **节点框**：圆角 8px，1px `#B5C7D8` 描边，浅底色；节点内标签 14px，节点标题 19–22px bold。
- **分组容器**：圆角 12px，底色 `#F4F7FA`，内间距 ≥ 20px。
- **对照表重绘成条目时**，每行必须有左侧色标（4×50px），不用横线画表格。
- **目录树与代码**：`Box`（`#F4F7FA` 或 `#F7F3E8` 底 + 圆角）+ 逐行 `Text`（Consolas 13–14px），行首缩进用空格，注释行用 `#546779`；禁止图片、禁止 `Table`。
- **禁止 emoji，也禁止使用图标组件（Font Awesome 等）**：图标导出后会变成嵌入图片，破坏「全部元素可编辑」的硬要求。需要图形语义时，用原生圆角色块 + 单字（如 装／读／执／验）。
- **固定宽拼接的精确对齐图形**（10 的三步链、15 的三列对照、19 的三步链）**不写 border**，描边会被额外计入宽度导致溢出，改用实心色块区分状态。

### 5.2 禁止项

- 禁止用位图或图表截图代替可编辑结构。
- 禁止使用图标组件与 emoji。
- 禁止把书稿 `chapter 02/figures/` 下的任何 png／svg 引入页面（包括 `08-skill-package.png`、`08-skill-hosting.png`、`08-skill-proof.png`）。
- 禁止把 2.8 的三张 mermaid 图直接渲染后贴入。

## 7. 讲稿备注（speaker notes）规范

- **每页必须有 `notes`**，是教师当页要读给学生听的自然逐字稿。
- 长度 120–300 字；第一人称直接讲观点，补充页面未展开的背景、原理或例子。
- 严禁元描述：「这一页展示了／本页聚焦于／下图描述了／上一步／这张表／接下来我们进入」。
- 分点逻辑必须换行分段。
- 备注内容必须能在书稿正文找到依据，不得杜撰数值或结论。
- **写入方式**：页面源文件写 `notes` 后运行注入脚本：
  `python .workbuddy/tools/add_pptx_notes.py "<slides 目录>" "<pptx 路径>"`
