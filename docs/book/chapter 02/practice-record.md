# 第二章练习记录模板

本文件供读者复制填写。空白字段表示尚未记录，不表示通过；真实模型、WorkBuddy 与离线模拟应分别建记录。

## 任务与环境

- 练习编号、开始/结束时间及时间区：待填。
- 对应小节、任务目标、预先定义的成功条件：待填。
- 路线：本地确定性 / 模拟 API / 真实 OpenAI API / WorkBuddy / 人工检查。
- 系统与 Python 版本、实际依赖版本、WorkBuddy 客户端版本：待填。
- 请求模型与响应返回的实际模型名、相关推理设置：待填；无该字段就写未提供。
- 输入目录、文件摘要或内容哈希、提示词与 Schema：待填。
- 可用工具、执行位置、权限范围、预算：待填。

不要记录 API Key 或可使用的认证令牌。

## 用量与比较

- 逻辑模型调用数、物理网络尝试数、实际工具执行数：分别填写；不可见的项目写未知。
- 输入/缓存/输出用量、适用的工具费用或产品积分：按实际返回口径填写。
- 总墙钟耗时、模型等待、工具执行、人工审阅：能区分则分别填写。
- 未解决问题、复现步骤、下一次只改变什么：待填。
