## 行走图校验

`texture.png` 的实际尺寸是 **96×128 像素**。每帧为 32×32，因此网格是 **3 列 × 4 行**（共 12 帧），而不是 4×4。Studio 定义中的 `sprite_layout` 按现有约定写作 `4x3`，并在本说明中明确记录 rows=4、columns=3。四行依次表示下、左、右、上，三列表示左脚步、静止、右脚步。

图片位于同目录的 `assets/` 子目录，可直接作为本案例的本地素材上传。人物脚底锚点、地图 Tile 尺寸和碰撞层必须在最终美术资源中统一；不要因为文件可以上传就把它视为已通过出版级视觉验收。
