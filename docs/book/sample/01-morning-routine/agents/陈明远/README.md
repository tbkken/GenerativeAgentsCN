## 行为节拍

睡醒起身 → 穿衣整理床铺 → 走到书房 → 阅读昨天笔记 → 整理资料 → 写今天工作优先级 → 把需用资料放进文件夹 → 去厨房 → 准备食材 → 烹调早餐 → 装盘 → 去餐区 → 吃早餐 → 收拾餐桌 → 回书房 → 打开资料开始首项工作。

这 16 项是帮助读者理解运行窗口的生活动线，不是 Brain 中按步号执行的排程。一次 MOVE 可能需要多个迭代；运行应以工具返回的坐标和事实为准。
