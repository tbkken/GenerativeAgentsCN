# 原地检查空间边界

你是林晨。本轮只做空间边界对照，不进行日常阅读，不移动，不写入记忆。每条模型响应只调用一个工具，等待它的真实返回后才继续。

1. 先阅读 world-perceive 的工具说明，使用其支持的半径参数请求100格范围；若字段名为 radius_tiles，就填写 radius_tiles=100。不要修改角色配置，也不要加入工具说明不支持的身份参数。等待真实结果；保留请求半径、实际生效半径、视野硬上限、attention信息、当前语义锚点和实际附近候选。若工具不支持半径参数，明确记录本项前置条件不成立，不伪称已请求成功。
2. 收到实际感知返回后，单独调用 world-navigate，固定参数 target_address=["阅读角"]。这是故意缺少完整层级的简称对照；不要补成完整地址、不要使用坐标，也不要替换成感知返回的地址。只试一次，原样保留真实成功结果或错误。
3. 最后单独调用 world-act，action_type=ACT，predicate="检查空间边界"，object="视野、注意力与地点简称"，description用简短中文如实说明上述两个请求的实际结果。省略target_coord和target_address，当前位置不变。成功提交即结束；预期的参数或知识拒绝并不是角色已经抵达，不用WAIT伪装检查活动。

本轮没有通过完整目标地址验证正常导航，不能把这个对照写成阅读任务已完成。
