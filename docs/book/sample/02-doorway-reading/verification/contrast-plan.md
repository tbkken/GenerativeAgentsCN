## 浏览器操作约束

- 先查看现有 UI 是否提供地图复制。若没有，不假设存在该按钮；可以在正式实验已持有独立地图副本后，通过地图编辑器设置封门碰撞，创建持有封门副本的对照实验，随即通过编辑器恢复公共地图的两格通路并重新检查。所有变化及实验身份都要记录，不能直接写地图文件。
- 简称与越界请求的确切参数名先以当前工具 schema 为准，不靠旧说明猜测。无效模型调用不构成预期分支的有效对照；如模型自行改了输入，保留原始结果并明确说明未覆盖。
- 对照只需短 Run：只读检查能在同一轮内完成，最后用 ACT“检查空间边界”留下实际响应摘要。ACT 文本不是检验结论，结论以真实 MCP 输入输出、坐标和 StepResult 为准。
- 门洞阻挡和权限拒绝是预期对照，不直接登记为系统缺陷。只有实际结果违反合同且与案例相关时才按用户规则停止，报告后等待批准。
