# 第1章Mermaid转换与对照记录

日期：2026-09-26。本章27组配图中，25组提供**上方Mermaid、下方原图参考**，2幅仅使用原图。原PNG全部保留并嵌在正文，原SVG与Python图源也保留，便于作者对照优化。

## 编辑规则

- 当前可编辑图源直接保存在正文Mermaid代码块，按对应的 `book-figure` 标识定位。
- 原图位于该代码块下方，标为“原图参考（转换前）”；原图不会随Mermaid修改而自动更新。
- 一组上下对照沿用一个原图号。原图注、证据日期和数据边界仍需结合相邻正文阅读。
- 不另设重复的 `.mmd` 源；原静态绘图脚本不再控制当前Mermaid。

逐图入口见[配图索引](figures/README.md)，维护步骤见[全书编辑说明](../mermaid-editing.md)。
