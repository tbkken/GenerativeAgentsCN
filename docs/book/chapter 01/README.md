# 第一章　认识大模型，读懂能力与评价

青禾社区学习中心准备举办一次开放日。一个人工智能助手很快写出了活动方案，但方案是否读对材料、满足房间容量、避开预约冲突，还需要进一步检查。我们就从这件小事出发，认识大模型，并学会判断它在什么条件下值得使用。

本章不要求编程基础。读完以后，你应能够解释 Token、训练、推理和上下文，分清模型与应用的能力来源，读懂常见评测指标，并为自己的任务设计一份小型评价方案。API 与 WorkBuddy 的具体操作放在第二章。
