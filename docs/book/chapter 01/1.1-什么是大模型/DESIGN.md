## 0. 项目画布

- 画布：**1280 × 720**（16:9）
- 页面安全区 padding：上下 20px、左右 64px → 内容可用宽度 **1152px**

## 1. 母版骨架（A / B / C 三区，逐页固定）

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |

### 2.2 面积分配（每页必须符合）

| 色彩角色 | 常规页 | Hero 页 |
| :--- | :--- | :--- |
| 主色（蓝） | ≤ 60% | ≤ 60% |
| 辅色（青绿） | ≤ 20% | ≤ 30% |
| 强调（橙） | ≤ 5% | 15–20% |
| 中性 / 白底 | 剩余 | 剩余 |

- 强调色**只出现在需要判断的地方**（超容量、冲突、未核验、检查点），不得用于装饰。
- 至少 6 页（01／06／12／16／23／26）的色彩比例与常规页显著不同。

### 2.3 渐变与半透明

- **本项目不使用渐变**，保持与书稿插图一致的扁平色块风格。
- 半透明仅用于：分组容器底 `rgba(39,111,191,0.06)`；重叠装饰层不高于 `opacity: 0.25`。
- 投影仅用于卡片：`boxShadow: '0 2px 10px rgba(32,52,75,0.06)'`，禁止重投影。

- 巨型数字必须与正文使用不同字重与字号（正文 17px regular ↔ 锚点 96px bold）。

## 4. 信息密度门禁

| 页面类型 | 最少元素 | 正文字数下限 | 主视觉占 B 区 |
| :--- | :--- | :--- | :--- |
| 封面 | 主标 + 副标 + 主视觉 | 20 | ≥ 35% |
| 目录 | 6 个条目 + 引导句 | 200（合计） | ≥ 30% |
| 内容页 · 单主题 | 标题 + 正文 + 主视觉 | 180 | ≥ 30% |
| 内容页 · 卡片组 | 标题 + 引导句 + N 卡 | 每卡 ≥ 70（合计 ≥ 210） | — |
| 章节扉页 | 大字 + 一句小标 + 轮廓图 | 30 | ≥ 40% |
| 结束页 | 回顾要点 + 落款 | 100 | ≥ 35% |

- 常规内容页留白 **≤ 35%**；Hero 页允许 40–50%，但留白须围绕焦点元素。
- 卡片填充率 ≥ 85%；高 ≥ 320px 的卡片正文 ≥ 90 字。卡片尾部元素用 `marginTop: 'auto'` 钉底。
- 横向兄弟卡片的「标题块 / 正文块 / 尾部条」三段在 y 轴必须对齐，偏差 > 16px 即返工。

| 等级 | 定义 | 本项目的形态 | 出现位置 |
| :--- | :--- | :--- | :--- |

| **L3 · 母版标记** | 全篇统一的小元素 | C 区左侧的 4×36px 蓝色竖标（全篇同位置同尺寸） | 全部内容页 |

### 5.1 图示绘制规范

- **箭头**：用 2px 线段 + 三角形/`›` 形箭头的 Box 组合实现；横向箭头高 2px、长 ≥ 28px；纵向箭头宽 2px、长 ≥ 24px。
- **节点框**：圆角 8px，1px `#B5C7D8` 描边，浅底色；节点内标签 14px，节点标题 22px bold。
- **分组容器**：圆角 12px，底色 `#F4F7FA`，内间距 ≥ 20px。
- **示意性内容必须标注**：凡涉及切分、编号、向量的示意，必须在同一视觉层给出「示意」字样，禁止让学生误认为是真实分词结果。
- **禁止 emoji，也禁止使用图标组件（Font Awesome 等）**：图标在导出后会变成嵌入图片，破坏"全部元素可编辑"的硬要求。需要图形语义时，用原生圆角色块 + 单字（如 入／算／显），或用纯几何色块表达。
- **连接线**：链接箭头用文字符号（`›`／`↓`）配合颜色，不用图片，也不用图标。

### 5.2 禁止项

- 禁止用位图或图表截图代替可编辑结构。
- 禁止使用图标组件与 emoji：导出后会成为图片，无法在 PowerPoint 里单独编辑。
- 禁止把书稿 `figures/` 下的任何 png／svg 引入页面。
- 禁止 200×70 之类的装饰小图塞进 A 区。
- 禁止用位图或图表截图代替可编辑结构。

## 7. 讲稿备注（speaker notes）规范

- **每页必须有 `notes`**，是教师当页要读给学生听的自然逐字稿。
- 长度 120–300 字；用第一人称直接讲观点，补充页面未展开的背景、原理或例子。
- 严禁出现「这一页展示了／本页聚焦于／下图描述了／接下来我们进入／建议先讲……」等对幻灯片的元描述与指导语。
- 若出现分点逻辑（第一、第二／首先、其次），必须换行分段，不得挤在同一段。
- 备注内容必须能在书稿正文中找到依据，不得杜撰数值或结论。
- **写入方式**：页面源文件中写 `notes` 属性后，运行项目脚本注入到 pptx 的备注页：
  `python .workbuddy/tools/add_pptx_notes.py "<slides 目录>" "<pptx 路径>"`
  （当前生成工具不会自动输出备注页，必须补这一步，否则演示时看不到讲稿。）
