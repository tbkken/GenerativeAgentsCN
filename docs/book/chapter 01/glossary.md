# 第一章术语速查

这张表用于回看概念，完整解释与算例请按正文阅读。

| 术语 | 本章含义 | 容易混淆的地方 |
| --- | --- | --- |
| 大语言模型（LLM） | 通过大规模训练获得广泛语言处理能力的模型 | 不是一个包办检索、执行和记忆的完整产品 |
| 基础模型 | 可作为多类下游任务基础的模型 | 与“大语言模型”侧重点不同，分类可能重叠 |
| 多模态模型 | 能处理多种信息形式的模型 | 能读图不自动意味着能生成图像、视频或语音 |
| 参数 / 权重 | 训练中调整、共同决定模型计算行为的数值 | 参数量不是上下文长度，也不是训练语料字数 |
| Token | 分词器或模型系统处理序列的单位 | 不能一律换算为一个汉字或一个词 |
| 嵌入（Embedding） | 将信息表示为便于计算的向量 | 内部 Token 表示与面向检索的文本向量用途不完全相同 |
| Transformer | 使用注意力等机制处理序列信息的一类架构 | 技术名称中的注意力不等于人的主观注意 |
| 预训练 | 通过大规模数据学习广泛规律的训练过程 | 不等于一次对话里临时提供材料 |
| 后训练 | 在已有模型基础上继续改善任务表现或行为 | 不必采用同一种算法或固定流程 |
| 推理（Inference） | 使用已训练模型处理输入并产生输出 | 与推理题中的逻辑推理不是完全相同的含义 |
| 上下文窗口 | 一次模型处理可容纳的信息范围 | 有效长度与额度分配依模型/接口；大窗口不保证用得好 |
| 持久记忆 | 应用保存并在以后适当时候读取的记录 | 不是把对话永久写入模型参数 |
| 检索增强生成（RAG） | 将检索得到的材料提供给生成过程 | 检索命中不等于回答正确，也不等于修改权重 |
| Agent | 围绕目标组织模型、状态与工具推进任务的应用方式 | 不要求固定的计划或反思流水线 |
| 基准（Benchmark） | 按一定协议组织的任务集与评价过程 | 一个基准不覆盖某种能力的全部实际用途 |
| 准确率 | 按规定评分正确的样本占比 | 必须同时看样本范围、分母和失败处理 |
| Precision / Recall | 报出结果的正确比例 / 应有结果被找出的比例 | 两者回答不同问题；零分母需要预定处理规则 |
| F1 | 精确率与召回率的调和平均 | 宏平均与微平均不同，也不能决定业务错误代价 |
| pass@k | 给定 k 次候选或尝试，至少一次通过的表现 | 还需验证和选择答案；不能等同一次交付可靠性 |
| pass^k | 同一任务重复 k 次都成功的表现 | 不同于 pass@k，也不同于自适应重试策略 |
| Recall@k | 前 k 个检索结果对相关证据的召回表现 | 文档、片段、答案命中的具体定义可能不同 |
| 校准 | 预测概率与实际发生频率的匹配程度 | 自信语气不是概率；Brier 也不只测校准 |
| TTFT | 按约定计时起点到第一个输出 Token 的时间 | 不是任务经过工具、检查后完成的总时间 |
| P50 / P95 | 延迟等观测的第 50 / 95 百分位 | 小样本与不同计算算法会影响结果 |
| 测试污染 | 测试内容或相近材料进入训练/调优，影响评价解释 | 不能仅凭模型分数高就断言污染存在 |
| 基准饱和 | 许多模型已接近某套测试的上限，难以再区分差异 | 不表示现实任务已经全部解决 |
| 模型快照 | 用于标识某个具体模型状态的名称或版本 | 持续更新的显示别名未必等于固定快照 |
