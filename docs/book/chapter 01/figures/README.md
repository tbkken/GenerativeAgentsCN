## 读图边界

- 1.1的Token切分、编号、向量、注意力与输出对照均为教学示意，不是真实内部数据。分类图不把基础模型与多模态画成互斥集合。
- 1.3的抽取数、重复成功概率及Wilson区间均为人工算例。重复曲线限于固定任务、固定成功概率与独立同分布的假设；区间不修复样本偏差。
- 1.4的视觉图只区分任务类型；示意柱形没有提供数值，不能用于读出真实数量。工具调用图保留宿主执行与环境状态。
- 1.5的柱形图沿用2026-09-25归档的厂商自报数据，条件、原始来源见正文与evidence-data.json；本轮没有更新模型成绩或重跑基准。
- 1.6的候选甲乙数据属于人工教学例子，不对应品牌或实际账单。
