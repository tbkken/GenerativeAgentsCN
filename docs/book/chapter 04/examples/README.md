# 人工数据演算

[comparison.json](comparison.json) 是教材作者构造的六行数据，服务于 [4.9](../09-comparison-and-your-study.md)。`A01` 等是教学行号，不是真实 Run 身份。数据没有模型费用、实际事件或实验包，不能当成仿真结果发布。

在仓库根目录运行：

```powershell
python -X utf8 "docs/book/chapter 04/examples/calculate.py"
```

脚本只用 Python 标准库，按脚本自身位置读取数据，可从其他工作目录启动；只向终端输出，不访问模型、浏览器、数据库或 Run 文件。它是本格式的演算程序，不是任意系统导出的通用分析器。

| 核对项 | A | B |
| --- | --- | --- |
| 闭环 / 初始任务 | 6 / 12 | 8 / 12 |
| 闭环率 | 50% | 约66.67% |
| 截止时未闭环 | 6 | 4 |
| 已闭环子集时延中位数 | 9.5分钟 | 13.5分钟 |
| 全部逻辑调用 | 370 | 480 |
| 全部物理尝试 | 411 | 516 |
| 逻辑调用 / 成功 | 约61.67 | 60 |
| 物理尝试 / 成功 | 68.5 | 64.5 |

零成功时，时延中位数和单位成功成本输出 JSON `null`，表示不可计算，不能显示为零成本。未完成任务不加入已完成时间数组；它们单独计数，不用60替代未知完成时间。

配图由[绘图脚本](../figures/render_figures.py)读取同一数据，标明人工示例。图表展示取舍，不用于证明某策略有效。
