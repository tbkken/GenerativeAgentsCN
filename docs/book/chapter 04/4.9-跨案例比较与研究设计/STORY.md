## 二、页面骨架

### 2.1 叙事主线

一句话主线：**同一批数字，换一个分母、换一个权重，就换了它回答的问题。**

四个递进问题贯穿全篇：

1. **事实怎么接成结果**——按 Run 收齐 Attempt、每项任务一行、闭环逐条核对（4.9.1、4.9.2）
2. **分母与权重是谁定的**——每 Run 同权与每项任务同权；成功子集用时不是全体完成时间（4.9.3、4.9.4）
3. **代价怎么报**——总投入与单位成功代价同时报告，调用数不等于货币费用（4.9.5）
4. **计划怎么写才被判分**——独立重复、统一尺度、六个问题、全部结果与局限（4.9.6–4.9.9）
