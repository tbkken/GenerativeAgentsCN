## 当前编辑方式与保留理由

- 关系、条件、时序、分类、分母计算和简单条形图：直接编辑正文的26个Mermaid块，在支持Mermaid的Markdown环境查看；下方原图只供转换前后对照。全书统一检查语法与实际渲染。
- `hall-map`、`gallery-layouts`、`closure-layouts`：保留坐标、比例、墙格、门洞和区域矩形，避免用关系图伪装真实几何。
- `teaching-comparison`：保留两面板散点、每Run比率、成功子集时延、汇总率／中位数及未完成数量；简单关系或柱形不能等价表达这些分布。
- [本轮完整记录](../mermaid-revision.md)说明逐图分类与检查范围。正文图号、图注、材料表、SOP和人工答案保持原有口径。
