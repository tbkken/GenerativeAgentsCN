# 第四章术语速查

| 术语 | 本章含义 | 容易混淆的地方 |
| --- | --- | --- |
| 研究问题 | 用预定条件和可观察结果回答的一项具体问题 | 不是“让所有角色表现更好”的泛愿望 |
| 基线 | 比较时保留的原方法或原条件 | 不是故意写差的对手 |
| 干预因素 | 本轮明确改变的策略、布局或条件 | 多处同时改动不能都归因于其中一项 |
| 对照 | 除预定变化外尽量保持共同条件的另一组 | 名称相同不证明输入和模型一致 |
| 观察单位 | 分母所对应的人、任务、事实或消息 | 不等于统计上的独立重复 |
| 独立重复 | 相同登记条件下新建的独立 Run | 续跑 Attempt、同 Run 多个人不是新增独立 Run |
| 区组 | 将相近环境或批次内的条件一起组织比较 | 不保证远端模型或网络完全稳定 |
| 混杂 | 其他因素与组别一起变化，使归因不清 | 事后解释不能替代原设计控制 |
| 主要指标 | 事先选定、直接对应研究问题的核心量 | 不在看到结果后换成最好看的指标 |
| 辅助指标 | 用于解释机制、失败、成本与覆盖的量 | 不能静默代替主要指标 |
| 百分点 | 两个百分比直接相减的差 | 从50%到60%是10个百分点，相对增长20% |
| 分母为零 | 没有满足该指标定义的观察对象 | 不适用，而非0%或100% |
| 未完成 | 截止时仍未达到预定完成条件 | 不是已经在截止时刻完成 |
| 删失 | 只知道截至某时刻事件尚未发生，之后时刻未知 | 不能直接删除或补成完成时间；不同中断机制应区分 |
| 未触发 | 研究要求的前置事件没有发生 | 如没有公告更正，就没有更正后传播起点 |
| 无法判断 | 证据不足以支持明确评分 | 不与业务失败或不适用混为一类 |
| 信息泄漏 | 角色通过不该获得的输入提前得到答案或私有事实 | 教师资料对读者公开不等于可发给全部角色 |
| 部分得分 | 按预登记规则满足部分条件 | 高部分分数仍可能没有一个可执行方案 |
| 敏感性分析 | 明确改变条件，观察原结论是否保持 | 属于新条件分析，不能覆盖原结果 |
| 外部验证 | 用独立现实资料检查模型结论的适用性 | 模型角色的一致意见不是现实民意样本 |
