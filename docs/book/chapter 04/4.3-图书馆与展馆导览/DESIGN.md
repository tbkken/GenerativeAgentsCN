### 5.1 平面图重绘规范（本节特有）

- 网格 24（宽）× 18（高），单元格边长 **16px** → 内区 **384 × 288**；外包墙体用实心深色块 `#20344B`，padding 8px → 外框 **400 × 304**（不写 border）。
- 房间用实心浅色块拼接，锚点为 `[x,y,width,height]` 换算：`left = x×16`、`top = y×16`。
  - 入口 `[1,1,22,6]` → `#F4F7FA`，`left 16 / top 16 / 352×96`
  - 甲厅 `[1,7,10,6]` → `#EDF4FC`，`left 16 / top 112 / 160×96`
  - 乙厅 `[11,7,12,6]` → `#ECF7F2`，`left 176 / top 112 / 192×96`
  - 休息区 `[1,13,22,4]` → `#F7F3E8`（高度补到 `80`，铺满内区底边），`left 16 / top 208 / 352×80`
- 标牌为 **16×16 橙色方块**（外扩 2px 白边用白色垫块实现，非 border）：基线 `[2,2,1,1]` → `left 32 / top 32`；对照 `[12,5,1,1]` → `left 192 / top 80`。
- 每张平面图正下方必须标注「**示意图**：非实际出生点、视野或寻路验收」。

### 5.2 绘制规范

- **箭头**：2px 线段 + `›`／`↓` 文字符号组合；横向箭头固定 44px 宽 Box，纵向箭头固定 40px 高 Box。
- **节点框**：圆角 8px，浅底色；节点内标签 14px，节点标题 20–22px bold。固定宽拼接的图形不写 `border`。
- **分组容器**：圆角 12px，底色 `#F4F7FA`，内间距 ≥ 20px。
- **对照条目**：每行必须有左侧色标（4×30px），不用横线画表格。
- **禁止 emoji，也禁止使用图标组件（Font Awesome 等）**：图标在导出后会变成嵌入图片，破坏「全部元素可编辑」的硬要求。需要图形语义时，用原生圆角色块 + 单字（如 甲／乙／牌／导）。

### 5.3 禁止项

- 禁止用位图或图表截图代替可编辑结构。
- 禁止使用图标组件与 emoji。
- 禁止把 `chapter 04/figures/` 下的任何 png／svg 引入页面（包括 `gallery-layouts.png`、`gallery-evidence-chain.png`、`gallery-scoring.png`）。

## 7. 讲稿备注（speaker notes）规范

- **每页必须有 `notes`**，是教师当页要读给学生听的自然逐字稿。
- 长度 120–300 字；第一人称直接讲观点，补充页面未展开的背景、原理或例子。
- 严禁元描述：「这一页展示了／本页聚焦于／下图描述了／上一步／这张表／接下来我们进入」。
- 分点逻辑必须换行分段。
- 备注内容必须能在书稿正文找到依据，不得杜撰数值或结论。
- **写入方式**：页面源文件写 `notes` 后运行注入脚本：
  `python .workbuddy/tools/add_pptx_notes.py "<slides 目录>" "<pptx 路径>"`
