# 第四章　面向问题的场景化应用

第三章说明如何让角色在共同世界中行动，第四章学习怎样利用这些行动回答具体问题：澄清需求是否减少走错窗口？交接清单是否减少遗漏？导览位置是否影响发现？记忆替代、讨论核对和跨日整理又各自带来什么收益与代价？

本章提供六个主案例、两个选修案例，以及跨案例比较方法。十节正文各有三个图位：其中26组采用上方Mermaid、下方“原图参考（转换前）”的双图对照，另4幅精确地图或统计图片独立呈现。先看空间、信息或时间关系，再读精确材料表与SOP，最后用人工判分图核对分母；教师答案与角色私有信息仍分别保留。
