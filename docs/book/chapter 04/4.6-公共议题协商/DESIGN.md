### 5.1 「示意界面」重绘规范（本章特有）

- 发言记录、场地说明牌、结果页摘要等一律用色块拼接，**禁止截图**；顶栏用 `#20344B` 实心条 + 白字标题，右上角固定一枚 84×30 的橙底白字「示意」标签。
- 对话行 = 左侧 4×28 发言者色标 + 20px 发言者名 + 16px 发言正文，行高固定 52–64px，等距排列。
- 理由／分歧表 = 每行左侧 4×40 色标 + 固定宽列，行底色区分状态（`#EDF4FC` 共同事实 / `#F7F3E8` 私有理由 / `#ECF7F2` 准确保留 / `#FFF4E6` 遗漏或抹平）；**不画横线表格**。
- 时间窗口条、刻度条等固定宽拼接图形**不写 border**，用实心色块区分状态。
- 每张示意界面正下方必须标注「**示意**：非系统截图、非 Run 结果」。

### 5.2 绘制规范

- **箭头**：2px 线段 + `›`／`↓` 文字符号组合；横向箭头固定 44px 宽 Box，纵向箭头固定 40px 高 Box。
- **节点框**：圆角 8px，浅底色；节点内标签 14px，节点标题 20–22px bold。固定宽拼接的图形不写 `border`。
- **分组容器**：圆角 12px，底色 `#F4F7FA`，内间距 ≥ 20px。
- **对照条目**：每行必须有左侧色标（4×30px），不用横线画表格。
- **禁止 emoji，也禁止使用图标组件（Font Awesome 等）**：图标在导出后会变成嵌入图片，破坏「全部元素可编辑」的硬要求。需要图形语义时，用原生圆角色块 + 单字（如 议／理／确／录）。

### 5.3 禁止项

- 禁止用位图或图表截图代替可编辑结构。
- 禁止使用图标组件与 emoji。
- 禁止把 `chapter 04/figures/` 下的任何 png／svg 引入页面（包括 `deliberation-constraints.png`、`deliberation-confirmations.png`、`deliberation-scoring.png`）。
- 禁止把 4.6 的三张 mermaid 图直接渲染后贴入。

## 7. 讲稿备注（speaker notes）规范

- **每页必须有 `notes`**，是教师当页要读给学生听的自然逐字稿。
- 长度 120–300 字；第一人称直接讲观点，补充页面未展开的背景、原理或例子。
- 严禁元描述：「这一页展示了／本页聚焦于／下图描述了／上一步／这张表／接下来我们进入」。
- 分点逻辑必须换行分段。
- 备注内容必须能在书稿正文找到依据，不得杜撰数值或结论。
- **写入方式**：页面源文件写 `notes` 后运行注入脚本：
  `python .workbuddy/tools/add_pptx_notes.py "<slides 目录>" "<pptx 路径>"`
