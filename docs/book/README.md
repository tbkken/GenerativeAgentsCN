# 基于大模型的智能体仿真：从能力理解到场景实践

本目录保存 GenerativeAgentsCN 配套书稿、写作设计与案例资料。全书按五章组织：认识大模型与能力证据，学习技术和工具，通过完整案例掌握系统，设计不同领域的仿真实验，最后完成可接手的项目交付。

五章均已完成正文初稿。第二章附教学代码，第三章附地图、人物、Skill 和验收材料，第四章附八类场景教案、研究模板与人工数据演算，第五章附项目委托、交付模板、假设预算和综合作业。新案例尚未完成系统运行验收；2026-09-25 的资料核查、离线检查与历史运行证据分开记录。

暂按“无 AI 基础、能阅读少量 Python 的应用实践者”设计。WorkBuddy 用于直观体验，API 用于理解可编程调用；代码解释输入、输出和执行过程。

每节回答：解决什么问题、原理是什么、为什么这样设计、如何操作、如何验证、可能在哪里失败。能力判断有测量依据，产品操作有版本依据，仿真效果有运行事实依据。

书稿写作与修订按用户确定的优先级选择表达形式：**图形 → 表格 → 格式化列表 → 短段文字**。关系、过程与空间优先画图，对照用表，步骤与要点用列表，必要解释贴近相应图表。五章54篇正文已逐节完成图解重排，共156组配图，146组采用“Mermaid在上、静态参考在下”，另10幅仅使用原图；每篇正文至少2幅。见[全书图解索引](visual-guide.md)。
