## 二、页面骨架

### 2.1 叙事主线

一句话主线：**来源清楚以后，还要决定每句话放在哪里——装错了不是模型的问题，是材料的问题。**

六个递进问题贯穿全篇：

1. **谁该看到什么**——同一张作者表，不等于同一份角色输入（5.3.1）
2. **地点归地点，答案归答案**——地图给出地点，不替咨询台回答问题（5.3.2）
3. **人与物分开核对**——人物初态与对象知识分别核对（5.3.3）
4. **装进实验的到底有几类东西**——完整资源闭包逐项点清（5.3.4）
5. **按什么顺序动手**——按内容关系安排作者操作（5.3.5）
6. **怎么知道真的做完了**——用状态表避免「文件有了就是完成了」（5.3.6）

### 2.3 Hero 定位

Hero 页 7 张（27 页的 26%，落在 20–30% 区间）：

- **01 封面**——作者表向四个接收者分支，橙色标出答案表不进角色与公共 Brain
- **04 信息分配矩阵**——本节唯一的「按接收者逐条看」的图，全页焦点
- **08 地图与三个对象**——World／Sector／四个 Arena 的几何示意 + 三个 Game Object
- **12 五名 Agent 名册**——五张身份卡横排，余真用青绿区分
- **16 资源闭包**——五类输入汇入一个独立实验
- **24 四栏状态**——同一份资源的四个核对面
- **27 结束页**——三句话收束
