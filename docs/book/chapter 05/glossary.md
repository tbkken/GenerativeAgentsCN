# 第五章术语速查

| 术语 | 本章含义 | 常见混淆 |
| --- | --- | --- |
| 项目约定 | 使用者、问题、范围、交付物和完成条件 | 愿望越宽泛不代表交付越完整 |
| 设计交付 | 可审读的输入、方法与计划，验收到可实施 | 不等于取得运行结论 |
| 运行交付 | 增加真实输入、全部运行、分析与接收记录 | Run完成不等于业务成功 |
| 需求—证据矩阵 | 将需求、判据、实际来源及缺口逐项关联的文档 | 文档编号不是系统业务身份 |
| 来源登记 | 记录资料从哪里来、采用什么、用于哪里 | 写“来自网络”不能精确定位 |
| 作者假设 | 为教学问题采用、需要解释影响的条件 | 假设不是已观测的现实规律 |
| 信息分配 | 谁初始知道什么，后来经什么渠道获知 | 作者全知表不应进入共同Brain |
| 精确行为文本 | 实际使用的完整Skill及其依赖和差异 | 一句SOP摘要不能代表包内全文 |
| 逻辑调用 | 应用层的一次模型调用任务 | 一个逻辑调用可能产生多次物理尝试 |
| 物理尝试 | 实际发出的模型请求尝试，包括重试 | 不等于业务任务数或成功数 |
| 提交边界 | 已完整提交、可作为世界事实读取的Step范围 | 工具接受、临时状态不等于完整提交 |
| 原始证据 | 保留原名、原字节与来源的导出或记录 | 标注图与清洗表属于派生材料 |
| 内容摘要 | 用于辨认和比较内容的哈希 | 不能证明业务正确、授权充分或因果关系 |
| 文件核验 | 检查文件身份、类型、大小、摘要与来源 | 不等于模型重新执行通过 |
| 回放 | 读取并归约已经提交的世界事实 | 不重新调用Brain、Skill或模型 |
| 复算 | 用既定判据和记录重新得到分析结果 | 不生成新的世界事实 |
| 重跑 | 用Run内嵌实验创建新Run并执行 | 不会自动使用公共资源的新修改 |
| 续跑 | 同Run、新Attempt，从完整边界继续 | 新建一个Run不能证明恢复通过 |
| 接收范围 | 接收者实际检查并记录的层次 | 签收文件不能等同所有层次通过 |
| 变更影响 | 一项修改涉及哪些材料、结论与验证 | 不引入资源Revision或自动更新关系 |
| FAIR | 数字资料便于寻找、访问、互操作和复用的原则 | 本章借鉴其组织思路，不宣称认证或要求全部公开 |

协议和动作的基础术语参见[第三章术语](<../chapter 03/glossary.md>)，实验比较参见[第四章术语](<../chapter 04/glossary.md>)。FAIR的来源与使用范围见[参考资料](references.md)。
