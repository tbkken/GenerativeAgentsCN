## 二、页面骨架

### 2.1 叙事主线

一句话主线：**结论不是写出来的，是沿着一条能查回来的链子走出来的。**

四个递进动作贯穿全篇：

1. **分开保存**——原始导出、解压副本、派生材料各有各的处理规则（5.6.1）
2. **三次追问**——主张问判据、判据问事实、事实问定位（5.6.2、5.6.3）
3. **拆开「完成」**——文字与状态能说明什么、还缺什么（5.6.4、5.6.5）
4. **写到落点为止**——人工阅卷留下可重复判断，对外结论不超过证据（5.6.6、5.6.7）

### 2.3 Hero 定位

Hero 页 7 张（24 页的 29%，落在 20–30% 区间）：

- **01 封面**——五步证据链：需求 → 补充 → 建议 → 去处 → 确认
- **05 证据目录分区**——`evidence/` 五个子目录各放什么、谁只能读
- **09 四次追问链**——主张 › 判据 › 事实 › 定位，含「教师答案 / 真实事实」两签
- **12 末步边界**——实线止于 Step76，虚线指向窗口外
- **17 两本账**——事实账与成本账四行逐行对齐
- **21 报告六步顺序**——研究条件 → 样本与边界 → 观察 → 代价 → 未完成 → 解释限制
- **24 结束页**——三句收束
