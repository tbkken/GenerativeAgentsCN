# 第五章　综合实战与交付：从需求到可接手的仿真项目

第三章说明系统怎样使用，第四章说明场景实验怎样设计。第五章把这些知识组织成一项能够交接的工作：需求有范围，材料有来源，行为有精确文本，结果有证据，接收者知道哪些检查已经完成、哪些还需要继续。

本章沿用第四章的“社区服务大厅”教学项目，比较直接建议与先澄清目的两种咨询策略。重点转向作者、复核者和接收者之间的材料交接，不另造一组行业案例，也不重复第三章的界面操作教程。
