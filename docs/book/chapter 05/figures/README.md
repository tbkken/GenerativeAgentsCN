## 历史素材

本章全部图形采用Mermaid在上、原图在下的对照形式。[原交付图脚本](render_figures.py)、[逐节图脚本](render_visual_revision.py)和旧PNG/SVG仅保留为先前改版的快照。后续修改当前图形无需运行Python，也不应据旧导出判断Mermaid是否已更新。

## 读图边界

- 当前服务大厅仍是待实施教学设计。流程、信息矩阵与交付图不表示资源已保存、实验已运行或接收已通过。
- 角色初始信息与后续真实交流分开；教师答案不进入公共Brain。对象响应与目标人物下一轮接收分别表示。
- 5.5调用与费用均按正文假设演算。单价不是服务商报价，项目监控阈值不是Runtime自动硬上限。
- 第76步对象提交答复不等于人物在窗口内完成接收和确认；图中下一轮仅说明条件，不假定本Run有第77步。
- 100分量表为教学建议；两组完整行为文本、人物目的、人工练习与实际结果的边界保持不变。
