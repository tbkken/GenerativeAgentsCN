### 5.1 绘制规范

- **箭头**：只用文字符号 `›`（横向）与 `↓`（纵向）；`›` 实测约 32px 宽，必须包进固定宽度 44px 的 Box 再计入一行总宽。
- **一行总宽复核**：`Σ元素宽 + Σgap×(n-1) ≤ 1152`。本项目已复算的关键行：
  - 04 三卡：`368×3 + 24×2 = 1152`
  - 05 三列分支：`368×3 + 24×2 = 1152`
  - 09 示意界面两面板：`552×2 + 16×1 = 1120`（含外层 16px 内间距）
  - 12 四行对照：`4 + 18 + 250 + 18 + flex + 18 + 330 = 1112`
  - 13 四步链：`255×4 + 44×3 = 1152`
  - 17 三层链：`340×3 + 44×2 = 1108`
  - 20 左右分栏：`380 + 32 + 740 = 1152`
  - 21 对照双列：`566×2 + 20 = 1152`
  - 23 六枚交付物：`172×6 + 24×5 = 1152`
  - 24 下行两块：`566×2 + 20 = 1152`
- **节点框**：圆角 8–10px，浅底色；节点内标签 13–15px，节点标题 20–22px bold。
- **分组容器**：圆角 12px，底色 `#F4F7FA`，内间距 ≥ 16px。
- **对照条目重绘成行时**，每行必须有左侧色标（4×48px），不用横线画表格。
- **固定宽拼接的图形一律不写 `border`**（描边会计入宽度导致 `child-containment` 溢出）：13 页四步链、11 页按钮路径、17 页三层链一律用**实心色块**区分状态（蓝底白字 / 浅蓝底蓝字 / 橙底白字 / 浅橙底橙字）。
- **包结构目录树、协议清单、CLI 命令清单**：必须用 Box + Text 的 `Consolas, monospace` 等宽色块重绘，**不允许截图**。
- **禁止 emoji，也禁止使用图标组件（Font Awesome 等）**：图标导出后会变成嵌入图片，破坏「全部元素可编辑」的硬要求。需要图形语义时，用原生圆角色块 + 单字（如 协／资／实／验）。
- **界面示意**：以 `#F4F7FA` 容器 + `#B5C7D8` 顶部窗口条 + 白色面板拼成，窗口条右侧固定放 13px 橙色「示意」二字。

### 5.2 禁止项

- 禁止用位图或图表截图代替可编辑结构。
- 禁止使用图标组件与 emoji。
- 禁止把书稿 `figures/` 下的任何 png／svg 引入页面（包括 `13-package-contents.png`、`13-handoff-levels.png`）。
- 禁止把 3.13 的两张 mermaid 图直接渲染后贴入；只取语义重绘。

- 正文中出现的尖括号统一用全角 `＜ ＞`，避免与 DSL 标签冲突。

## 7. 讲稿备注（speaker notes）规范

- **每页必须有 `notes`**，是教师当页要读给学生听的自然逐字稿。
- 长度 120–300 字（上限 300，英文与数字按字符逐个计入）。
- 第一人称直接讲观点，补充页面未展开的背景、原理或例子。
- 严禁元描述：「这一页展示了／本页聚焦于／这张表／下图描述了／上一步／接下来我们进入／最后一段」。
- 分点逻辑必须换行分段。
- 备注内容必须能在书稿正文找到依据，不得杜撰数值或结论。
- **写入方式**：页面源文件写 `notes` 后运行注入脚本：
  `python .workbuddy/tools/add_pptx_notes.py "<slides 目录>" "<pptx 路径>"`
