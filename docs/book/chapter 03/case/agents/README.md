# 四名人物的作者资料

人物全部为教学虚构。每人目录中的说明用于填写公共智能体的身份、特质、生活习惯和当前目标；头像与 `4x4` 行走图是本书原创矢量绘制素材，尚未上传。实验出生空间独立设置，不把坐标写进公共 Agent 核心。

| 姓名 | 教学角色 | 初始 Arena | 目标区域 | 资料 |
| --- | --- | --- | --- | --- |
| 林岚 | 组织者 | 公共大厅 | 服务台、公告栏与活动室 | [人物说明](lin-lan/README.md) |
| 周宁 | 志愿者 | 手作室 | 公共大厅及需要协助的场所 | [人物说明](zhou-ning/README.md) |
| 陈晨 | 阅读来访者 | 交流室 | 阅读室 | [人物说明](chen-chen/README.md) |
| 许安 | 手作来访者 | 阅读室 | 手作室 | [人物说明](xu-an/README.md) |

安排不同初始 Arena，是为了让当前空间选择器产生可区分的位置，并观察跨房间移动。叙事起点是四人已经进入学习中心；他们从各自初始区域开始行动，没有模拟地图外进场过程。

在“智能体”页分别创建四个人，再切换“人群”页建立本案例的四人选择集。人群表示作者选择集合，不是一个第五位角色。记录每名实际资源的稳定身份；本目录名只是资料定位标签，不能冒充保存后生成的业务身份。

依次上传每人 `portrait.png` 与 `sprite-4x4.png`。本材料行走图为 128×128 像素，当前界面按上传尺寸识别为 `4x4`，没有需要另行选择的布局控件；保存后核对预览与识别结果。候选显示高度为 1.8 格。保存公共资源后，重新导入或在新实验选择，才能让实验副本获得这些图片；公共资源后续更新不会自动覆盖已有实验。

人物图是简洁的彩色教学标记，衣着颜色分别为蓝、绿、紫、橙，便于跟踪。仍须在地图背景上验脚底、遮挡和缩放，不能因为图片尺寸一致就推定回放视觉已经通过。
