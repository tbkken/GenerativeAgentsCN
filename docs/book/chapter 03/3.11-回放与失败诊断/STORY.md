## 二、页面骨架

### 2.1 叙事主线

一句话主线：**画面只是线索，能证明发生的只有已提交的事实。**

四个递进问题贯穿全篇：

1. **凭什么算发生**——动作选择被接受、世界提交、StepResult 与持久边界之间的关系；回放只读已提交事实（3.11.1 / 3.11.2）
2. **在界面里怎么追**——先记 Step 上限，再用时间线定位事件，再分别核对人物、会话与对象状态（3.11.3 / 3.11.4）
3. **问题属于哪一类**——边界处理、行为问题、执行问题、页面展示问题，处理方式完全不同（3.11.5）
4. **怎样写下来**——最小证据包的六个要素；历史微案例只保留历史含义（3.11.6 / 3.11.7）
