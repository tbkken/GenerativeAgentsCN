## 二、页面骨架

### 2.1 叙事主线

一句话主线：**同样是「再运行一次」，身份和边界不一样，能证明的事情也不一样。**

四个递进问题贯穿全篇：

1. **谁是谁**——Run 与 Attempt 为什么必须分开（3.10.1）
2. **从哪接**——已提交边界为什么比画面进度更重要（3.10.2）
3. **怎么核对**——暂停后看检查点，继续后核四件事（3.10.3—3.10.4）
4. **别混路**——取消不等于立即停止，重跑不等于续跑（3.10.5—3.10.6）

### 2.3 Hero 定位

Hero 页 7 张（24 页的 29%，落在 20–30% 区间）：

- **01 封面**——Run A 内嵌尝试链与 Run B 重跑的分叉视觉
- **05 两条身份线**——Step 轴上的 Run A／Run B 泳道，全篇身份主轴
- **10 已提交边界**——帧带 + 判定 + 两条恢复分支
- **15 检查点详情**——示意界面（窗口 + 字段 + 详情 + 按钮），全篇唯一取证入口
- **20 取消时序**——四条泳道的时序示意，问号标出未验收边界
- **23 交付物**——身份对照表示意骨架 + 三枚签
