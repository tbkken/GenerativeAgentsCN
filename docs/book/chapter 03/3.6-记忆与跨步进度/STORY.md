## 二、页面骨架

### 2.1 叙事主线

一句话主线：**记忆让角色跨轮延续，但永远不能替代世界事实。**

五个递进问题贯穿全篇：

1. **哪三种内容容易混**——世界事实、角色认识、待确认进度，不能互相冒充（3.6.1）
2. **记忆怎么管理**——append / search / supersede / invalidate，更正不删历史（3.6.2）
3. **检索到底是什么**——file_lexical 词法匹配，不是向量数据库（3.6.3）
4. **进度怎么写**——动作之前写“待确认”，world-act 接受即结束本轮（3.6.4）
5. **页面上怎么验收**——记忆面板是摘要，验收要答四个问题（3.6.5）
