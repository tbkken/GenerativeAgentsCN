### 5.1 绘制规范

- **箭头**：`›`／`↓`／`≠` 文字符号；横向箭头一律包进**固定宽 44px 的 Box** 再计入行宽；纵向箭头放在高 32–40px 的居中 Box 内。
- **节点框**：圆角 8px，浅底色；节点内标签 14–15px，节点标题 18–22px bold。
- **分组容器**：圆角 10–12px，底色 `#F4F7FA`，内间距 ≥ 16px。
- **固定宽拼接图形不写 `border`**（描边会计入宽度导致溢出），用实心色块区分状态（蓝底白字 = ACTIVE／浅底彩字 = 分支结果／米底 = 历史保留）。
- **一行总宽复核**：`Σ元素宽 + Σgap×(n-1) ≤ 1152`。
- **示意界面**：窗口 = 中性底容器 + 蓝色标题条 + 白色导航列与字段行；右上角放橙色「示意」胶囊；字段值一律写「待填」，不虚构节点 UUID、Step 编号或重要度数值。
- **对照表重绘成条目时**，每行必须有左侧色标或整行浅底，不用横线画表格。
- **禁止 emoji，也禁止使用图标组件**：需要图形语义时，用原生圆角色块 + 单字或编号。

### 5.2 禁止项

- 禁止用位图或图表截图代替可编辑结构；禁止任何界面截图。
- 禁止使用图标组件与 emoji。
- 禁止把书稿 `figures/` 下的任何 png／svg 引入页面（包括 `06-memory-lifecycle.png`、`06-pending-confirmation.png`）。
- 禁止把 3.6 的两幅 mermaid 图直接渲染后贴入；只取语义重绘。

## 7. 讲稿备注（speaker notes）规范

- **每页必须有 `notes`**，是教师当页要读给学生听的自然逐字稿。
- 长度 120–300 字；第一人称直接讲观点，补充页面未展开的背景、原理或例子。
- 严禁元描述：「这一页展示了／本页聚焦于／下图描述了／上一步／这张表／接下来我们进入」。
- 分点逻辑必须换行分段。
- 备注内容必须能在书稿正文找到依据，不得杜撰数值或结论。
- **写入方式**：页面源文件写 `notes` 后运行注入脚本：
  `python .workbuddy/tools/add_pptx_notes.py "<slides 目录>" "<pptx 路径>"`
