## 转换时保留的边界

- Brain 图表达本案例选用的条件式 SOP，子 Skill 按需调用；方法不是内核强制流水线，运行配置继续约束循环与无进展行为。
- `world-act` 被接受、世界执行、整步 StepResult、持久提交与回放可见边界分开；接受动作不证明业务已经完成。
- 成功动作后根 Skill 本轮结束；必要便签在动作前写，下一轮按实际事实确认，不在动作之后追加完成记忆。
- 人物对话仍是两名真实参与者的 SPEAK；对象回复仍引用真实请求身份，在整步提交后进入目标的下一轮，不画成广播或共享上下文。
- 实验副本、封存边界、Run 与 Attempt、最新恢复快照分别表达；取消图继续标明在途同步请求的中断行为尚待专项验收。
- 源码合同、教学设计、历史证据与实际运行结果保持区分；不补填青禾的 Run、Step、消息、状态、费用或得分。
