## 二、页面骨架

### 2.1 叙事主线

一句话主线：**实验的生命周期只有两个状态，`DRAFT` 可以改，`SEALED` 不能再改；运行状态是另一条信息。**

五个递进问题贯穿全篇：

1. **创建到底生成了什么**——不是几条公共资源的链接，而是一份独立材料（3.8.1）
2. **草稿能改，就该改完再核对**——坐标、时间、Brain、保存结果都要重开确认（3.8.2）
3. **预检检查什么、不检查什么**——四类材料与依赖，不等于角色已穿过门（3.8.3）
4. **封存边界在哪里**——确认执行才封存并创建 Run；要改内容就复制成新实验（3.8.4）
5. **归档、恢复与删除的边界**——展示管理，不改实验与 Run 的状态（3.8.5）
