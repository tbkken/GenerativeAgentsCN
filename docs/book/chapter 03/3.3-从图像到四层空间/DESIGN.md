- 投影仅用于卡片：`0 2px 10px rgba(32,52,75,0.06)`。

### 5.1 绘制规范

- **箭头**：文字符号 `›`／`↓`，外包固定宽 44px 的 Box（计入行宽）；横向箭头长 ≥ 28px。
- **节点框**：圆角 8px，1px `#B5C7D8` 描边（仅独立节点），浅底色；节点内标签 14px，节点标题 20–22px bold。
- **固定宽拼接的精确图形**（隔断条、门洞、工具条、四层树）：**不写 border**，用实心色块区分状态。
- **示意界面**：米底 `#F7F3E8` 窗口框 + 白底字段行 + 蓝底按钮条；窗口右上角或标题栏固定 14px「示意」标签（`#546779`）。
- **一行总宽复核**：`Σ元素宽 + Σgap×(n-1) ≤ 1152`。
- **对照表重绘成条目时**，每行必须有左侧色标（4×40px），不用横线画表格。
- **禁止 emoji 与图标组件**：需要图形语义时，用原生圆角色块 + 单字。

### 5.2 禁止项

- 禁止用位图或图表截图代替可编辑结构。
- 禁止使用图标组件与 emoji。
- 禁止把书稿 `figures/` 下任何 png／svg（`03-semantic-map.png`、`03-map-layers.png`、`03-spawn-selection.png`）引入页面。
- 禁止把三张 mermaid 图直接渲染贴入；只取语义重绘。

## 7. 讲稿备注（speaker notes）规范

- **每页必须有 `notes`**，是教师当页要读给学生听的自然逐字稿。
- 长度 120–300 字；第一人称直接讲观点，补充页面未展开的背景、原理或例子。
- 严禁元描述：「这一页展示了／本页聚焦于／下图描述了／上一步／这张表／接下来我们进入」。
- 分点逻辑必须换行分段。
- 备注内容必须能在书稿正文找到依据，不得杜撰数值或结论。
- **写入方式**：页面源文件写 `notes` 后运行注入脚本：
  `python .workbuddy/tools/add_pptx_notes.py "<slides 目录>" "<pptx 路径>"`
