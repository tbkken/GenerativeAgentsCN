## 二、页面骨架

### 2.1 叙事主线

一句话主线：**图像要变成空间，必须把尺度、语义、通路、出生四件事分别录入并分别核对。**

六个递进问题贯穿全篇：

1. **尺度与层级**——32×24 格怎么读，四层空间怎么分（3.3.1）
2. **背景入库**——新建地图、导入原图、切片绑定（3.3.2）
3. **语义地址**——四层地址树与状态外观绑定（3.3.3）
4. **通路**——画出的门必须设为可走，路径检查四结果（3.3.4）
5. **出生装配**——人物图片规格与空间选择器（3.3.5）
6. **证据边界**——旧案例怎么用、本节留下什么（3.3.6）

### 2.3 Hero 定位

Hero 页 7 张（25 页的 28%，落在 20–30% 区间）：

- **01 封面**——图片 → 空间的对照视觉，橙色标注「画出的门」
- **04 四层空间**——World→Sector→Arena→Game Object 全篇结构主轴
- **08 三类地图信息**——显示／语义／碰撞三分支 + 底部证据警示
- **12 地址树**——编辑器中的四层地址树与字段面板
- **16 地图与门洞**——32×24 示意网格、四 Arena 范围、y=13 隔断与三处门洞
- **20 出生装配**——四人物 → 选择器 → 核对的汇流图
- **25 结束页**——三个反问收束
