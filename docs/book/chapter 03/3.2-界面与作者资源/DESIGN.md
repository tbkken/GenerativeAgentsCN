- 画布：**1280 × 720**（16:9）

### 5.1 绘制规范

- **箭头**：用文字符号 `›`／`↓`，装入固定宽 44px（横向）或固定高 28px（纵向）的 Box 后居中。
- **节点框**：圆角 8px，浅底色；节点内标签 14px，节点标题 19–22px bold。
- **分组容器**：圆角 10–12px，底色 `#F4F7FA`，内间距 ≥ 16px。
- **对照表重绘成条目时**，每行必须有左侧色标（4×N px），不用横线画表格。
- **示意界面拼装规范**（本节专属）：
  1. 结构：顶栏 42–48px（蓝底白字，右侧固定放一枚 84×22 的白色圆角 chip 写「示意」）→ 主体行（侧栏 148–220px 浅蓝底 + 主面板白底／中性底）→ 按钮条 44–56px。
  2. 字段行：高 42–54px，圆角 6px，底色 `#F4F7FA`／`#EDF4FC`，内写字段名（14px `#546779`）+ 右侧值占位（13px `#B5C7D8`）。
  3. **固定宽拼接的横条不得写 `border`**——描边会被计入宽度导致溢出；状态区分一律靠实心色块（蓝底白字／浅蓝底蓝字／浅橙底橙字）。
  4. 「示意」标必须与界面块处在同一视觉层（顶栏 chip 或面板右上角角标），不得放到页脚。
- **禁止 emoji，也禁止使用图标组件（Font Awesome 等）**：图标导出后会变成嵌入图片，破坏「全部元素可编辑」的硬要求。需要图形语义时，用原生圆角色块 + 单字。

### 5.2 禁止项

- 禁止用位图或界面截图代替可编辑结构。
- 禁止使用图标组件与 emoji。
- 禁止把 `chapter 03/figures/` 下的任何 png／svg 引入页面（包括 `02-editor-scope.png`、`02-identity-content-placement.png`）。
- 禁止把 3.2 的两个 mermaid 图直接渲染后贴入。

## 7. 讲稿备注（speaker notes）规范

- **每页必须有 `notes`**，是教师当页要读给学生听的自然逐字稿。
- 长度 120–300 字；第一人称直接讲观点，补充页面未展开的背景、原理或例子。
- 严禁元描述：「这一页展示了／本页聚焦于／下图描述了／上一步／这张表／接下来我们进入」。
- 分点逻辑必须换行分段。
- 备注内容必须能在书稿正文找到依据，不得杜撰数值或结论。
- **写入方式**：页面源文件写 `notes` 后运行注入脚本：
  `python .workbuddy/tools/add_pptx_notes.py "<slides 目录>" "<pptx 路径>"`
