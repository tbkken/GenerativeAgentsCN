## 二、页面骨架

### 2.1 叙事主线

一句话主线：**先确认自己站在哪一层范围，再谈改了什么。**

三个递进问题贯穿全篇：

1. **我在改哪一份**——公共作者资源还是当前实验（3.2.1）
2. **这些东西分别是什么**——七类资源，以及两处最容易误解的能力（3.2.2）
3. **先准备谁**——四位人物、一个选择集、一份模型配置（3.2.3–3.2.5）
4. **怎样才算准备好**——身份、内容、装配分别核对，给出交付清单（3.2.6）

### 2.3 Hero 定位

Hero 页 6 张（22 页的 27%，落在 20–30% 区间）：

- **01 封面**——示意控制台：顶栏 + 侧栏 + 主面板，「实验 / 基础配置」两组并列
- **04 两层范围**——公共作者资源 → 递归复制 → 实验独立副本，本节主概念图
- **11 「＋ 新建智能体」表单**——全页示意界面：页签 + 身份字段 + 特质与计划字段
- **17 「＋ 新建模型」表单**——全页示意界面：连接字段 + 聊天字段 + 保存/测试连接按钮条
- **20 三件事分别核对**——稳定 ID / 内容摘要 / 实验装配三条分支汇聚到同一边界
- **22 结束页**——三条核对顺序收束

### 2.4 Rhythm（版式节奏）

```
01 hero  封面 · 左标题 + 右示意控制台

05 sup   非对称 40:60 · 左示意侧栏 + 右三行对照
06 sup   左标题 + 右三条判断条目
```

- 非对称版式：05／06／08（左右分组）／09／12（左标题+右四行）／13／15／18／21 共 8 页 = 36%，加上 12／21 的行内三段对齐，非对称占比 ≥ 40%。
