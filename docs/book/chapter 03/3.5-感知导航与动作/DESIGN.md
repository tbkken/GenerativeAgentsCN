### 5.1 绘制规范

- **箭头**：2px 线段 + `›`／`↓` 文字符号组合；横向箭头长 ≥ 28px，纵向箭头长 ≥ 24px。
- **`›` 箭头必须包进固定宽 44px 的 Box** 再计入一行总宽：`Σ元素宽 + Σgap×(n-1) ≤ 1152`。
- **固定宽拼接的精确对齐图形（路径格、范围嵌套、刻度条）不写 `border`**，描边会计入宽度导致溢出；用实心色块区分状态（蓝底白字／浅蓝底蓝字／浅橙底橙字）。
- **示意平面图**：米底 `#F7F3E8` 容器 + 房间浅底色块 + 通道留白 + 坐标标注 13px `#546779`，右下角固定放橙色小胶囊「示意」。
- **示意界面**：中性底 `#F4F7FA` 容器 + 字段行色块，同样标注「示意」。
- 节点框：圆角 8px，浅底色；节点内标签 14px，节点标题 18px bold。
- 分组容器：圆角 12px，底色 `#F4F7FA`，内间距 ≥ 20px。
- 行式条目每行必须有左侧色标（4×40px），不用横线画表格。
- 禁止 emoji、禁止图标组件；图形语义用原生圆角色块 + 单字或短标签。

### 5.2 禁止项

- 禁止用位图或图表截图代替可编辑结构。
- 禁止把书稿 `figures/` 下的任何 png／svg 引入页面（含 `05-perception-limits.png`、`05-movement-budget.png`、`05-action-ownership.png`）。
- 禁止把 3.5 的 mermaid 图直接渲染贴入，只取语义重绘。

## 7. 讲稿备注（speaker notes）规范

- **每页必须有 `notes`**，是教师当页要读给学生听的自然逐字稿。
- 长度 120–300 字；第一人称直接讲观点，补充页面未展开的背景、原理或例子。
- 严禁元描述：「这一页展示了／本页聚焦于／下图描述了／上一步／这张表／接下来我们进入」。
- 分点逻辑必须换行分段。
- 备注内容必须能在书稿正文找到依据，不得杜撰数值或结论。
- **写入方式**：页面源文件写 `notes` 后运行注入脚本：
  `python .workbuddy/tools/add_pptx_notes.py "<slides 目录>" "<pptx 路径>"`
