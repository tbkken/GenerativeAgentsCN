# 第三章　在共同世界中行动：用完整案例学习 GenerativeAgentsCN

第二章产出了开放日筹备方案。第三章把同一个问题放进有空间、时间、记忆和反馈的世界：场地预约发生冲突，组织者核实并调整安排，公告栏更新，来访者通过实际渠道获知消息，再改变行动。我们由此学习系统的作者资源、实验装配、运行控制与事实回放。

本章以“青禾社区学习中心开放日”为贯穿案例，包含四位人物、四个活动区域和两个拥有独立 Skill 的对象。每节先用图建立空间、时序或身份关系，再用表格与步骤说明操作和证据。全章 34 个图号，其中 31 组采用“上方可编辑 Mermaid、下方转换前原图”的对照形式，3 幅几何示意图独立保留；不把模型说过的话直接当成世界已经发生的事。
