## 二、页面骨架

### 2.1 叙事主线

一句话主线：**纸上写了，不等于世界里发生了；要评价，先保证信息走的是真实渠道。**

四个递进问题贯穿全篇：

1. **凭什么算发生**——咨询、更新、获知三段取证，答案不能提前共享（3.1.1）
2. **谁在行动**——四个人物与两个对象；计划人数不是 Agent 数（3.1.2）
3. **怎么界定位置与信息**——图片管外观、碰撞管通行；作者知道不等于角色知道（3.1.3 / 3.1.4）
4. **窗口能证明什么**——三种时间、48 步与移动常量、动手前的自检与练习（3.1.5 / 3.1.6 / 3.1.7）

### 2.3 Hero 定位

Hero 页 7 张（24 页的 29.2%，落在 20–30% 区间）：

- **01 封面**——原排期（纸面）与世界里实际发生的对照
- **04 信息来源与角色边界**——全节的信息渠道主轴，图 3.1-1 语义重绘
- **07 四个人，两项对象能力**——人物与对象的身份划分
- **11 从地图图片到空间语义**——32×24 格「示意」地图 + 四层职责
- **15 观察窗口时间轴**——图 3.1-2 语义重绘，48 步落在哪里
- **21 开始前的自检**——三步链路 + 巨型序号
- **24 结束页**——三条结果收束
