## 二、页面骨架

### 2.1 叙事主线

一句话主线：**不替角色写结局，只写它做决定的条件与证据。**

五个递进问题贯穿全篇：

1. **是什么类型、在哪里使用**——五份 Skill 的依赖与绑定（3.4.1）
2. **SOP 怎么写**——条件分支 + 一次 world-act + 硬上限（3.4.2）
3. **系统怎么读**——front matter 合同、call_skill、子 Skill 缺 world-act、max_hops（3.4.3）
4. **页面上怎么建**——技能/大脑入口、Scripts 与 MCP 核对、对象绑定、递归复制（3.4.4）
5. **怎么判断做对了**——输入、工具证据、提交动作三层连看（3.4.5）
