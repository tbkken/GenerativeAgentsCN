### 5.1 绘制规范

- **箭头**：文字符号 `›` `↓` `‹`，横向箭头包在固定宽 38–44px 的 Box 内计入总宽。
- **节点框**：圆角 8px，浅底色 + 1px 描边；节点内标签 14px，节点标题 19–22px bold。
- **固定宽拼接的图形不写 border**（描边计入宽度会溢出），用实心色块区分状态。
- **判断分支（菱形语义）**：橙色系小方框 + 「是／否」出线标签。
- **示意界面**：`#276FBF` 标题条 + 右上角白底「示意」胶囊；侧栏 `#EDF4FC`、窗体 `#F4F7FA`、输入行白底圆角。
- **代码色块**：`#20344B` 深底、白/浅灰文字、等宽排布，逐行 Text。
- 禁止 emoji、禁止图标组件；图形语义用圆角色块 + 单字（如 类／装／核）。

### 5.2 禁止项

- 禁止位图 / 截图 / `figures/*.png|svg` / mermaid 渲染产物。
- 禁止界面截图；界面一律拼装并标注「示意」。

## 7. 讲稿备注（speaker notes）规范

- **每页必须有 `notes`**，教师当页照念的逐字稿，第一人称。
- 长度 120–300 字；分点逻辑换行分段。
- 严禁元描述：「这一页展示了／本页／上一步／这张表／下图／接下来我们」。
- 内容必须能在 3.4 书稿正文找到依据，不杜撰数值。
- 写入方式：页面源文件写 `notes` 后运行
  `python .workbuddy/tools/add_pptx_notes.py "<slides 目录>" "<pptx 路径>"`
