## 保留的实验空间

- 双向机动车道、中央绿化隔离带、两侧方向明确的非机动车道和人行道。
- 南侧非机动车道与同向机动车道之间的一处中段护栏缺口。
- 缺口后的公交候车亭与仍可见的骑行通道。
- 相互分开的两处正式过街通道。
- 单排商铺后方的 U 形支路及其两端连接，可作为更长的候选绕行路线。路线的合法性和代价仍须写入实验规则并实际核验。
- 校园入口、住宅门面、地铁入口、骑手驿站、早餐、便利店、打印、茶饮与医院入口。

人物、车辆、摄像头、处罚提示牌和信号灯未画入背景。需要变化的设施仍按独立 Game Object 素材设计，不增加建筑切片。

已核对画面为 3:1 宽幅，底部第二排住宅已移除，校园纵深明显收短；道路方向箭头、中央连续隔离带、南侧缺口、两处过街点和后方支路仍可辨认。
