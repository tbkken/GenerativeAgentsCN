## 1. 研究问题与首轮边界

**在相同出行任务和基础道路条件下，摄像头及其可感知的提示，能否降低不同时间压力骑行者的违规借道比例？这种变化伴随多少出行成本？**

首轮研究一次出行中的即时选择，比较设备设置、明确告知与时间压力的作用。处罚后的再次出行、长期记忆演化、缺口封闭和道路改造留到后续独立实验。

不预设摄像头一定有效、赶时间一定违规或借道一定更快。零违规、条件间无明显差异以及增加绕行或迟到，都可以成为结果。这里的政策比较是仿真条件下的比较，不能直接当作现实人群效果估计。

本轮只观察表中指定行程。取餐、取件、送学和其他完整生活过程不扩展成额外任务链。角色先进入正常骑行阶段，不能直接出生在缺口；小王的起点是本次送件行程的上游位置，不虚构当前地图中打印店在缺口上游。

所有出行均经过同一南侧东行研究走廊。各角色的起终点可以不同，但**同一角色在六组条件中使用相同起点、终点、出发时间、物理能力、背景和初始记忆**。目标建筑入口和共同到达界线要在网格设计后明确，不能用“看起来到了医院附近”替代到达判定。

每名角色都经历全部六组条件。时间紧张程度由本次任务截止时间设置，不写成固定的人设结论。人设不规定必选路线，也不把某个年龄、职业或性格等同于必然违规。角色之间是整体背景差异，本轮不把它们解释为某个单一人格变量的因果效应。

首轮建议统一角色的基础最大移动能力、视野和注意力参数，以减少物理能力差异；这属于受控实验简化，并非对原表“快、慢”骑行描述的完整还原。自主等待或路线选择造成的实际耗时仍按事实记录。需要研究个体速度差异时另设条件。

### 建议规模与运行单位

建议每个条件、每个角色做 3 次独立重复：**6 条件 × 4 角色 × 3 重复 = 72 次出行**。这是探索性规模建议，不是统计功效保证，也不是已批准启动的运行数量。

每个 Run 只安排 1 名研究对象，避免把被试之间的跟随与交互同时混入首轮比较。如需要背景交通，它不计入被试人数；其组成、初始位置和行为配置另行固定。不能把同一 Run 内多名 Agent 当作相互独立的重复。

按“同一角色＋同一重复编号”建立配对区组，每区组包含六个条件。正式生成运行清单时预先安排条件次序，记录随机化方式；不固定永远先跑 C0，也不根据前一组的结果调整后续条件。

每次从头运行使用新的 run_id 和独立记忆。暂停恢复保持同一 run_id，不能增加重复次数。若模型支持 seed，则记录并按既定区组规则使用；不支持时如实标记，不承诺模型输出可逐字复现。相同初始设置也不保证交互后的交通轨迹完全一致。

## 4. 时间压力与路线成本

先完成地图网格、通行边界和移动预算的核验，再确定时间数值。当前不把图片像素数直接转换为米或分钟，也不在提示词中编造“借道节省三分钟”。

对每名角色定义：

- `t0`：本次出发的带时区仿真时间，六组保持一致。
- `Δt`：每 Step 的虚拟时长，所有条件保持一致。
- `K_ref`：在无额外等待、遵守本实验规则的前提下，从该起点到该终点所需的最短理论移动步数，使用允许的合法路线和实际移动预算计算。
- `T_ref = K_ref × Δt`：理论通行参照，不是对 Agent 实际到达时间的保证，也不指定 Brain 的动作序列。

建议截止时间：

| 时间条件 | 截止时间建议 | 设计意图 |
| --- | --- | --- |
| L 充裕 | `t0 + 2 × T_ref` | 留有接近一倍理论通行时间的余量 |
| H 紧张 | `t0 + T_ref + Δt` | 合法理论通行仍有机会按时到达，但余量较小 |

这组公式需要在参数定稿时检查区分度，尤其不能使 L、H 经步长取整后变成同一截止时间。公式或交通设置的调整应发生在比较前，形成新的完整运行批次；不能看过违规结果后只改不符合预期的组。

Agent 得到具体截止时间和当前仿真时间，自行形成时间压力判断。研究侧可按 `(截止时间 − 当前时间 − 剩余合法理论通行时间)` 计算客观余量，用于对照模型表达；两者分别记录。

比较成本时保留全部三条路线的真实路径、通行条件和测量依据。较窄车道只提供空间条件，不自动产生拥堵。首轮建议固定一套仍可通行、可能产生有限延误的交通背景，其真实生成机制尚待核验；如果最终采用通畅背景，应在方案中明确，不能仍把实验描述成“拥堵迫使骑行者借道”。

仿真步长、地图尺度、速度、具体出发时刻和总步数暂不填写伪精确值。总观察窗口在比较前统一确定，覆盖三条路线的合理行程与有限等待。到达后可在终点有原因、有结束边界地等待，不把正常等待判成卡死，也不把到达业务目标写成系统提前结束条件。

## 6. 客观判定与评估指标

### 判定边界

本实验拟定义一个固定的“禁止研究对象借用的机动车道区域”，明确排除允许横穿的正式过街区域。它是需要写入实验的显式研究规则，不是本稿对现实道路法规的断言。

研究侧必须读取完整已提交移动轨迹，检查路径是否与该区域相交，不能只看每 Step 终点而漏掉步内穿行。因有效范围或轨迹缺失不能判定时，结果为未知，不填零。

只要已经有明确借道证据，后续中断不抹去该阳性结果。完整观察窗口内没有借道，才可记为该窗口内未借道；提前中断且尚未观察到借道时记为未知。到达后个体观察可结束，但需有完整的到达前轨迹。

需要区分四件事：设施存在、Agent 实际感知、实际违规通行、满足抓拍条件。覆盖区与工作状态结合轨迹可以支持事后计算“满足抓拍条件”；若没有对应已提交事实，不能把它写成“已经抓拍”或“已经处罚”。研究侧派生统计不反向改变世界。

| 指标 | 统一定义与处理 |
| --- | --- |
| 出行借道结果 | 每次预先纳入的出行是否至少发生一次研究区内违规借道。未到决策区也保留在分母中，另报到达决策区比例 |
| 借道比例 | 完整可判定出行的借道人次/人次，同时列出全部分配数、未知数与缺失原因；有未知时补报全部分配人次下的最低/最高可能比例，不把缺失剔除后称作完整结果 |
| 机动车道行驶距离 | 累计已提交路径在禁止借用区域内的相交长度；网格尺度未确定时报告格长，不虚构米数。合法过街不计入 |
| 到达与通行耗时 | 从预定出发边界到首次满足目标区域到达条件的虚拟时长。按事实时间精度报告，不从模型推理墙钟耗时计算 |
| 等待与绕行 | 累计有效 WAIT 的虚拟时长，并区分计划等待与系统回退；实际总路径长度相对该任务合法理论最短路径的增加量 |
| 迟到与未到达 | 已到达者按首次到达时间是否超过 deadline 判定；未到达者单列。观察终点超过 deadline 时可判定未按时到达，但不能给它伪造到达耗时 |
| 感知与理由 | 引用设备/提示首次真实返回的感知记录及当时位置，另记录模型是否表达理解、风险判断与理由；工具返回和模型理解不混为同一指标 |
| 执法相关记录 | 设备状态、覆盖命中、满足抓拍条件、实际抓拍事实、处罚事实分别记录；没有实现或没有事实证据的字段标注不可用/未知 |

主要比较按预先分配的 C0/C1/C2 条件进行。按“看见/未看见”拆分可用于机制描述，但不能直接当成随机分组的因果比较，因为路线和注意力本身会影响是否看见。

先报告每个角色和每组的分子、分母、未知/未完成数量、单次结果与配对差异；比例差用百分点表达。汇总时各角色等权，并保留异质性，不因某角色多跑几次就提高其权重。初始小样本主要用于描述，不能仅凭少量重复或模型理由宣布统计显著、政策有效或现实可推广。

### 失败、恢复与缺失

所有分配出行保留记录。模型失败、取消、超出循环安全预算、系统回退与未到达分别记录。修复后重跑保留原始失败及关联说明，不能只留下成功结果。

同一 Run 的全部 Attempt 合并审阅，按提交 Step、Agent 和完整事实身份去重。未提交 Trace 不当作已发生行为；不通过记忆文本补造世界轨迹。未到达者的耗时按观察终点截尾，单列报告，不用观察窗口长度冒充其到达耗时，也不只展示已到达者平均值而隐藏未到达数量。运行 COMPLETED 与到达、违规、迟到等实验指标独立。

## 7. 研究记录与系统能力衔接

每次出行的研究索引至少记录：条件编号、角色编号、重复区组、experiment_id、run_id、全部 attempt_id、地图与规则内容标识、模型/Skill 配置、起终点、仿真时间和 deadline、观察窗口、执行状态、指标值及证据引用。

每条关键证据能定位到 Run、Attempt、Agent、Step 和已提交事实或 Trace。记录数据来源：当前包内配置、真实感知返回、世界提交、事后派生统计或模型解释。区分模型逻辑调用和物理重试，研究资源消耗使用墙钟与调用量；出行效果使用虚拟时间与轨迹。

这些索引和报告是案例资料或 Run 的文件化派生内容，不新增数据库运行事实，也不要求 Skill 为回放额外输出机器合同。Brain 用自然语言组织感知、记忆和行动；世界变化仍通过 MCP、World Commit 和 StepResult。

摄像头通过合法 world-act 提交有证据的抓拍活动，不能绕过 World Commit 直接改世界，也不在首轮生成罚款。骑行者的自述不能决定自己是否客观违规或已经被拍。正式运行前需验证客观判定和记录入口；基础状态换图不代表完整执法机制已经存在。
