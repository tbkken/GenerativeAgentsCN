1. 原包 Manifest 确认 experiment_id 为 `6092db14-4f63-4986-8dd8-b5c81b07ffca`，Agents 入口为 `agents/index.json`。实际文件是 `var/packages/experiments/workspace-27a40af2feec4a278aa5216c4c79f16d/agents/index.json`，只读检查李子健条目为 `sprite_display_tiles: 2.0`、`sprite_layout: 4x4`、视野 20、注意力 8，图片路径均指向实验内部。该文件 SHA256 为 `3ce834f8efcb887dec3d7812717c1c4dd6f84cd187ea057afc109b126a87b54e`。
2. `generative_agents/ga_studio/workspace.py:544` 通过 `source.model_dump(..., exclude_none=False)` 导入完整公共字段，只替换图片引用和实验位置，没有丢弃显示大小。
3. `generative_agents/web/static/console-api.js:3687` 的 `fillSharedAgentEditor` 正确把 `agent.sprite_display_tiles` 写入表单。公共编辑入口在 3774 行调用它；封存只读入口也复用它。
4. 同文件 `openAgentEditor` 的草稿分支（3728–3738 行）另外手写一套回填逻辑，填了目标、特质、视野和注意力，却没有填 `agentEditSpriteDisplayTiles`，也没有调用共享填充函数。刷新后的空表单因此保持空白；若该弹窗此前编辑过另一角色，则还存在沿用旧输入值的代码风险。
5. 同文件 3664–3671 行把空输入解析成 null；3867、3877 行将解析结果写入 Agent，3909 行保存草稿。因此直接保存可能把原有正确值覆盖为 null。这是代码路径确认的后果，本次未通过修改真实草稿去触发。
6. 与该字段直接相关的 `tests/foundation/test_agent_visual_scale.py` 只检查公共/运行模型的可选值及范围。现有前端测试搜索未发现该字段的回填回归覆盖，未保护“已有显式值 → 打开草稿 → 不修改该字段 → 保存”的路径。

诊断结论：两套前端回填逻辑分化造成字段遗漏。当前无需靠重新导入或手工补值恢复原草稿数据；需要修复 UI 回填，并通过原页面确认正确展示和保存保留。
