## 问题与修改

1. 实验中心 → 新建实验 → 填写名称和目标 → 下一步，用户尚未选择资源时，第一个公共人群被自动勾选。
   - 原因：人群选项加载器在选择为空时自动加入第一项。
   - 修改：移除此默认行为。重新点击“新建实验”时清空前一次向导的人群选择；同一次向导前后返回或重新加载可用人群时，保留用户主动选择。取消全部选择或所选人群已不可用时保持为空，不替换成其他人群。
2. 选择资源页面仍显示“实验发布时冻结地图与素材的完整快照”“创建后资源组合保持只读”，确认页也显示“资源组合只读”。
   - 修改：统一为创建时完整复制资源及依赖，公共资源后续修改不影响本实验，草稿可编辑，封存后不可修改；封存后需要调整则复制为新的独立实验。确认页初始状态显示“草稿（DRAFT）· 尚未执行”。缺少人群的校验提示从“已发布人群”改为“公共人群”。

## 重启影响的只读核查

主 Agent 补充要求确认重启是否影响其他正在运行的 Run，未授权本次进行实机重启验证。

- `restart-web.bat` 只结束监听 8000 且命令行匹配 `generative_agents.web.main` 的进程 ID，未递归结束子进程。
- `ga_runtime/supervisor.py` 以独立 `subprocess.Popen` 启动 `generative_agents.cli.main run resume`，输出直写 Run 日志；`ga_studio/web.py` 的关闭阶段只关闭 Studio 数据库，没有终止 Runtime 的钩子。
- 据此判断，重启 Web 不应直接停止独立 Runtime，但旧 Web 内存里的进程字典、槽位和等待线程会随 Web 退出而消失。此判断是源码证据，不是当前溪谷大学 Run 的实机重启存活验收。
- 本修复只涉及静态资源，直接刷新即可完成验收，不需要为此对其他 Run 做重启操作。
