## 1. 先确定实验目的

总体目的：以新港西路电动自行车通行为场景，研究不同治理措施如何通过骑行者的环境感知、时间压力和历史经验，影响其借用机动车道的选择，并比较治理效果与出行成本。

首阶段聚焦：**在相同出行任务和基础道路条件下，摄像头及其可感知的提示，能否降低不同时间压力骑行者的违规借道比例？这种变化伴随多少额外通行成本？**

这里的“能否”是研究问题，不预设政策必然有效。拟观察实际借道比例、机动车道内行驶距离、通行耗时、等待与绕行、迟到情况，以及真实感知和决策过程。模型理由用于辅助解释，实际行为与耗时须来自提交事实。

后续再通过重复出行和可信执法反馈研究记忆与行为演化。一次通行不作为长期学习效果的证明。仿真比较与现实治理效果推断之间仍需行为数据校准。

## 2. 地图必须承载的行程

第一阶段以南侧东行非机动车道为核心研究走廊。对照运行采用相同的指定起终点、基础地形与可比较的交通条件；不同角色可以有各自出行任务，但同一角色跨治理条件的任务保持一致。

| 空间阶段 | 本图安排 | 对实验的作用 |
| --- | --- | --- |
| 出发与接近 | 南侧西段、骑手驿站附近及其后的连续骑行路段 | Agent 从正常出行进入研究区，接近过程能够消耗时间；不直接出生在缺口 |
| 共同决策区 | 约画面三分之一处，后方支路入口与机动车道护栏入口相邻 | 避免 Agent 到达缺口时已经错过绕行入口；在同一局部环境中形成选择 |
| 行为差异区 | 非机动车道及公交站旁较窄段、相邻机动车道、商铺后方 U 形支路 | 为直行、等待、绕行和借道提供物理条件 |
| 回流与汇合 | 公交站后的护栏回流口，以及更下游的支路出口 | 让借道与绕行都能回到南侧东行非机动车道，记录借道段的完整边界 |
| 后续行程与到达 | 汇合后至东端的连续道路及目的地入口 | 观察真实通行耗时和迟到情况，不在完成一次动作选择后立即结束实验 |

两处正式过街通道仍在研究区外围，中央绿化隔离带在借道入口与回流口之间连续。研究中的借道是进入**同向机动车道**，不要求骑行者横穿中央隔离带。

## 3. 三条路线与等待选择

| 路线/选择 | 空间组织 | 成本与结果的判断 |
| --- | --- | --- |
| 持续沿非机动车道 | 从共同决策区沿现有车道经过公交站旁路段，再向东 | 路线持续可通行；不能为迫使违规而把合法路线完全堵死 |
| 减速或等待 | 在上游路段或合适的局部停留位置等待条件变化，之后继续 | 等待位置、原因、边界和是否影响其他交通需在配置中确定；本图未单独完成等待湾设计 |
| 合法绕行候选 | 从左侧支路进入，绕过单排商铺后方，再从右侧支路回到原方向车道 | 物理距离更长；允许通行的主体、方向及具体成本由显式实验规则和路径核验确定 |
| 机动车道借道候选 | 从左侧护栏开口进入同向机动车道，越过研究段，再由下游开口回流 | 不预设一定更快；是否违规、借道距离和耗时须按规则及真实轨迹判定 |

两处中段开口分别服务于进入和回流，但“回流口”只是研究中的用途描述，不自动赋予开口合法性，也不意味着其他 Agent 物理上只能单向通过。

## 4. 固定地图与治理变量

比较摄像头和提示效果时，基础背景、护栏开口、道路和目的地保持一致。摄像头、提示牌等治理设施以独立对象配置，不烘焙进背景。其位置、状态、覆盖范围及 Agent 能否实际感知到需分别定义。

上游应留足行程用于接近治理信息和决策地点。具体视野、信息出现时机和两处选择入口的距离，应按最终网格校准，不能为保证“看见摄像头”而绕过视野硬上限。

画面不预画拥堵、违规骑行或处罚结果。拥堵和实际延误是否形成，需要按已核验的运行能力和可比较的交通配置定义；不能从候车亭图案推断队列或虚构节省时间。若以后研究缺口封闭或路线改造，它们属于另一组明确的空间干预，不混入首阶段摄像头条件比较。
