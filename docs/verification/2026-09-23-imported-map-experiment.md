## 原因与修复

实验构建器先复制共享 ResourceSet，其中已包含导入地图的图片；随后又接收物化地图收集到的同一路径图片。原判断只检查路径是否存在，误将相同附件视为 Skill 内容冲突。

现改为比较内容字节：同路径、同内容合并为一份；同路径、不同内容继续拒绝，并报告真实的资源附件冲突。文件路径输入仍经过原有安全路径检查。
