## 实施范围

| 请求或页面 | 现在的读取方式 |
| --- | --- |
| 实验列表、包目录、Run 历史 | 查询层分页，只装配当前页摘要；最近 Run 使用分组查询，不读取所有历史 |
| 实验 GET | 默认 overview，无大地图、Agent 正文或重复 definition；编辑显式 `view=definition` |
| 实验 status、Run 状态、回放 availability | 独立轻量接口；质量与恢复检查另行请求 |
| 地图、空间素材、Agent、Crowd、Skill、模型列表 | 分页摘要；选择资源后请求详情；凭据状态查询不解密密钥 |
| 实验包内资源 | 复用经过完整性校验的只读包和解析索引，不为每条摘要物化全部附件 |
| 回放帧与时间线 | 限定 Step 窗口；选 Agent 时才读取当前帧审计 |
| Agent 结果、对话、记忆、质量 | 分区、分页；结果投影和质量缓存只处理新增提交事实，可删除后重建 |
| 模型 Trace、日志、检查点 | 游标、字节窗口或分页；大 Payload 详情显式加载 |
| 图片 | ETag / 304；96、192、384 像素 WebP 缩略图；包内原图采用共享句柄流式传输；封存资源使用 immutable 缓存 |
| 导入导出预览 | 导出预览只读元数据；导入复用有容量限制、能失效的验证结果 |
| 创建、复制、预检、封存、新建 Run、恢复、重跑、目录重建 | Web 使用 `Prefer: respond-async` 获取任务状态地址；后台执行，页面轻轮询；操作绑定 Experiment / Run |
| 结果制品导出 | 后台任务，保存提交边界；下载定位并验证选定制品，不扫描和加载所有 ZIP |
| 前端模块与轮询 | 编辑器、Phaser 按页面加载；只请求当前结果标签；隐藏暂停，终态停止；图片只加载当前引用集合 |
| 新建实验 | 第一步立即打开；第二步再获取分页资源选项 |

缓存由文件身份、mtime、大小及 Windows ChangeTime 等指纹失效；首次及变更后的严格校验保留。目录链接、ZIP 不安全成员和帧完整性验证没有因性能优化而删除。图片请求在网络发送失败时释放文件和缓存引用，草稿替换与图片快照保持一致。后台任务使用跨进程 owner lease，避免另一个 Web worker 启动时误判活跃任务中断。
