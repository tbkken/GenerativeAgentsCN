# 实验智能体空间树选择

## 交互与规则

- 入口：实验 → 智能体 → 编辑 → 初始位置与空间。
- 初始位置改为可搜索、展开的四层空间树：世界 → 区域 → 场所 → 对象。选择场所或对象后，自动填写坐标、真实初始地址，并补充该地点到已知空间。
- 坐标取所选节点中心附近、完整地址严格相同的可行走格；同距按 Y、X 确定。中心被障碍物或另一对象占据时不会写入错误地址，没有可行走格时禁止确认。
- 原有坐标打开时保持不变，仅在确认新选择后计算中心；取消或 Escape 不写回。
- 常用地址、已知空间、批量初始位置均复用同一选择器。已知空间只添加明确选中的对象，同场所合并；批量操作为每个 Agent 独立补充空间，保留原有知识与其他用途地址。
- 原始名称与地址用数组保存，名称中的 `/`、` > `、中英文逗号不会被重新拆分。公共 Agent 仍不保存空间；封存实验只读。
