# 保存关联关系与启动前保存状态修复

用户已明确同意修复设计复核指出的两项问题。范围限定为局部保存的 Crowd 关系与保存失败后的启动保护。

## 实现

- 前端保存同时提交 agents 和 crowds，Studio PATCH 白名单同步支持 crowds；继续使用同一包锁、完整依赖校验、内容摘要冲突检查及已有暂存/异常回滚机制。没有放宽非法关系校验。
- 所有调用 saveDraft 的程序化修改在进入队列前标记未保存；失败单独记录在当前实验，保留本地内容。预检和启动等待全部已排队保存结束，若仍有保存失败则明确阻止，要求用户先修正并成功保存。
- 保存队列仍能在失败后接受正常重试；只有成功保存或显式重新载入服务端事实才解除相关失败状态。启动失败处理不再用服务端旧定义覆盖保存失败的本地配置。
- 保存与等待保存绑定实验 ID 和打开代数，迟到失败不能污染另一个实验，迟到成功不能替换新实验页面。
