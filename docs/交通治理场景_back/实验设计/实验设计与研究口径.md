# 实验设计与研究口径

## 1. 三份需求的统一理解

主题是“一名电动自行车骑行者接近护栏缺口时，如何在道路条件、规则、当前任务、时间压力和既有经验之间权衡”，不是全城交通流仿真，也不是预先规定高压力必然违规。

Word 给出研究边界，Excel 的 Sheet1 第 2—13 行列出 12 个功能节点，PNG 将其细分为 17 个环节。图中的事件记录、重要性提取、反思总结以及解释输出，是表格中记忆与实验记录节点的细化，不意味着必须创建 17 个 Skill、17 次模型调用或一个系统工作流编辑器。

统一采用以下解释：

- **客观层**：真实车道、护栏与缺口、车辆位置和运动、摄像头实际状态、执行轨迹及依规则得出的违规/抓拍/处罚结果。
- **骑行者认知层**：本人已知规则、视野与遮挡允许看到的道路和标志、本人获知的结果、计划、主观压力、经验与推测。
- **研究记录层**：同时保存前两层的证据及关联，允许分析“措施存在 → 被感知 → 影响选择 → 实际结果”。研究者知道不等于骑行者知道。

PNG 的判断菱形应理解为权衡问题；Word 明确否定机械的条件分支。PNG 中“是否发生事故/冲突”比 Word 的首阶段描述更宽，暂列扩展指标，不能把未建模的事故率输出为 0。`enforcement_result` 统一拆解为抓拍与处罚，但保留来源字段映射。图中的“记忆写入后影响未来决策”保留，反思不设成所有事件影响行为的必经门槛。

规则使用研究者在实验包内明确配置的场景假设。原资料没有指定适用城市、具体法规、罚额、抓拍概率及通知延迟；这些不能由模型临时创造。本稿没有提出真实法律结论。

## 2. 实验单位与人员

首个场景保持一名焦点骑行者；人物差异通过独立实验/Run 比较，不能把不同条件的人同时放入地图，误当作相互独立样本。

建议作者人物模板覆盖三个方向，均为待确认的研究设定：普通通勤者、具有严格任务时限的配送骑手、时间充裕的办事骑行者。记录守法倾向、风险偏好、时间敏感程度、道路熟悉度、初始计划及经验。描述倾向而不预写最终选择。若要识别时间压力的独立影响，应在同一人物配置下只改变截止时间，而不是同时把职业与性格全部换掉。

同一人物重复经过缺口，才能观察自然积累的长期反馈。独立 Run 默认不能继承上一 Run 的私有记忆：实验要自包含。可以在同一个 Run 中设置多次有实际移动过程的出行；也可另设明确标注的“预置经验条件”，但这不等于系统已支持自动跨 Run 学习。

背景机动车及非机动车的实际运动属于原需求。静态对象只能表示静态障碍，不能宣称它们已实现速度、快速接近或避让。背景参与者采用何种可验证运动机制，列为能力方案中的待确认项。

## 3. 行为与两个循环

一次接近缺口应具备：非机动车道继续前进路线、缺口进入机动车道路线、合法绕行路线，以及安全等待位置。堵塞或通行效率差异必须有真实状态及执行成本，不能只在提示词中声称“前方很堵”。

| 研究中的行为选择 | 系统表达 | 核查要求 |
| --- | --- | --- |
| 保持非机动车道 | MOVE | 整条执行路径保持在允许车道，不能只看终点 |
| 合法绕行 | 经合法路线的 MOVE | 当前最短路不保证合法，需路径约束或足够明确的中间目标 |
| 经缺口进入机动车道 | MOVE | 物理上能通过；是否违规由客观规则判定 |
| 等待 | WAIT | 有真实等待原因与期限，等待推进虚拟时间 |
| 减速 | 需要真实的速度/移动预算变化 | 少移动几格只是粗粒度近似，不能称为已实现减速动力学 |
| 局部调整或重新规划 | Brain 更新个人计划记忆 | 不新增 REPLAN 世界动作；规划文本不能凭空移动人物 |

物理可达与规则许可必须分开：如果直接把机动车道设成骑行者不可通行，实验就无法观察“可以走但违规”的选择。反过来，也不能因为骑行者在文字中选择“合法绕行”，就让无约束 BFS 抄近路通过违规车道。

时间压力小循环建议表达为：读取有效计划 → 基于已知路线与当前虚拟时间估算 ETA → 权衡 → 提交一次动作 → 下一轮读取实际结果 → 修正计划和压力。当前根 Brain 成功调用 `world-act` 后立即结束，因此不能把同轮动作后的计划更新写成现有 Skill 已能继续执行。

长期记忆循环建议表达为：已获知事件 → 写入个人事件记忆 → 重要或重复经历时按需反思 → 保存带证据的认识 → 后续检索参与判断。`未收到通知`不等于`客观未抓拍`，`主观认为没事`应明确写成认知而非客观事实。

## 4. 连续时间压力

建议先固定一个透明、可重算的实验公式，以下只是待校准起点：

`slack_minutes = deadline - subjective_eta`

`score = clip(50 - 50 × slack_minutes / tolerance_minutes, 0, 100)`

`tolerance_minutes` 必须大于零；ETA 等于 deadline 时得分 50，提前至少一个 tolerance 得分 0，迟到至少一个 tolerance 得分 100。可用低于 33、33 至不足 67、67 及以上分为低中高。没有严格截止时间时单独标注“无时限约束”，不伪造一个 deadline。

主体时间敏感度和迟到后果可以影响 tolerance 或另行进入决策，但不要用不透明的两次加权重复计算。研究记录同时保留截止时间、ETA、slack、公式参数、分值及主观理由。公式放在实验自己的只读计算 Skill/脚本内，输出不得更改世界时间。

骑行者用已知信息估算 ETA；研究者可以另算客观行程时长，两者必须分字段。不能把含隐蔽摄像头、未来堵塞解除时间或后台处罚结果的全知 ETA 注入 Brain。

## 5. 政策对照设计

建议先固定几何和道路干扰，分别操纵“摄像头是否实际运行”和“处罚提示是否对骑行者可见”。二者分开，才能区分实际执法与可感知提示的作用。

| 条件 | 摄像头实际运行 | 提示 | 目的 |
| --- | --- | --- | --- |
| C00 | 否 | 无 | 基线 |
| C01 | 否 | 有 | 提示信息效应；提示文字不得虚构实时抓拍事实 |
| C10 | 是 | 无 | 实际执法及后续经历效应 |
| C11 | 是 | 有 | 二者共同作用 |

“无提示”不自动等于摄像头不可见。设备自身可见性、安装位置与遮挡另行记录并在比较中控制；如果研究的是隐蔽设备，感知接口必须确实隐藏它。合法绕行代价、护栏缺口通行状态和道路拥堵可作为后续独立因子，避免第一轮同时改变所有条件。

初始建议比较 4 个政策条件 × 2 档截止时间 × 3 个人物模板，共 24 个条件；每条件重复数 R 待模型吞吐和行为方差确定，共 24R 次独立 Run。这是设计规模建议，非已启动任务。相同人物、地图和模型参数尽可能配对；记录种子，但相同种子不保证远端模型逐字可复现。

若要专门研究长期记忆，另开展重复出行组：保持政策条件稳定、让同一 Run 内的同一骑行者再次经过缺口。初始经验与自然积累经验分组报告，不将反复同一人每一步当成独立样本。

## 6. 指标与解释

- 违规率：发生违规的有效接近次数 / 有效接近次数；因封闭缺口根本不存在违规机会的条件需单独解释。
- 抓拍率：实际被抓拍的违规事件数 / 满足研究定义的违规事件数；另报满足设备覆盖条件的分母。分母为零时为不可计算。
- 处罚率及通知延迟：处罚与抓拍分别统计；未通知和未处罚分开。
- 出行结果：真实路径、到达率、按时到达率、实际耗时；未到达需标注截尾，不能用计划到达替代。
- 反馈机制：提示是否进入感知输出、通知是否已投递、相关记忆是否被实际检索、计划是否更新、后续选择是否变化。
- 实验质量：工具失败、回退 WAIT、非法路径、隐私泄漏、缺失客观判定、缺失记录分别统计，不能混入业务违规率。

连续占用机动车道应有稳定的事件段身份：进入开始一段、离开结束，同一段每 Step 被观察不能重复算多次违规或多张罚单；合法例外由包内规则定义。又一次离开后重入则是另一事件。判定检查整段实际路径，不能漏掉“中间越线但终点回到非机动车道”。

研究记录按包内 experiment_id/run_id/attempt_id、Agent、Step、decision/encounter/event 身份关联。世界结果源自 StepResult；感知与决策理由源自实际工具响应和 Trace。解释文本是模型陈述或研究者分析，不等于已证明的内部因果机制。

Run 的 COMPLETED 只表示执行完成；违规与否、是否准时是本实验指标，不得固化成所有实验的内核成功标准。
