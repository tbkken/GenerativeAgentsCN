# 知行自习室 · 独立地图作者草稿

Map 名称：知行自习室。Map key：`desk-tidying-v1-map`。拟定 12×12 格，所有坐标仅为待校准布局。

| 层级 | 独立 key | 名称 | 空间语义 |
| --- | --- | --- | --- |
| World | desk-tidying-v1-world | 知行学习空间 | 一处用于观察个人学习活动的小型室内空间。 |

先以单一书桌对象承载桌面材料状态，避免增加第五层。空桌与学习材料仍作为不同视觉素材；是否能在同一对象上组合、按状态换图，必须通过管理台验证。如果需要分开建同级物品节点，先更新本文件，不同时维护两个互相矛盾的状态源。

房间底图为 1254×1254，原设计提议的 768×768 不再作为本版实际图片尺寸。格坐标与图片像素分开记录，不能把透明图片全画布误当作实体碰撞范围。

拟议布局：书桌实体约 x3–9、y4–6；人物位于南侧 [6,7]。材料覆盖书桌中央；角色视野覆盖材料；不要求角色出门或移动。

对象状态草案：`arrangement: scattered | stacked`。这是本例用户定义字段，不是系统内置活动字典。是否可由感知直接读取、如何与图片关联，都处于待验收状态。

素材图层：房间底图 → 空书桌 → 当前材料状态图 → 独立角色。示意布局不等于已经在系统中设置渲染顺序。回放只依据已提交状态选择图片，不能按 Step 自动切换。
