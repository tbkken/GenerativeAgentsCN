# 人物录入补充

四人的性格、年龄与经历基本合理。本次把人物整理成可按管理台字段填写的 `姓名/studio-definition.json`，已通过当前 `StudioAgentDefinition` 校验。

这些文件是作者录入底稿，不是已上传资源，不包含公共资源 ID、地图坐标或可直接运行的实验包。图片的 `portrait_asset_id` 和 `sprite_asset_id` 留空，必须由页面上传返回的实际资源标识填写，不能把磁盘文件名填成资产 ID。

| 页面字段 | JSON 字段 | 说明 |
| --- | --- | --- |
| 模板键、显示名称 | agent_key、name | 保留现有四人身份；已有公共 Agent 时编辑原资源，不重复创建同名人物 |
| 年龄、天生特质、背景经历 | scratch.age、innate、learned | 角色放在背景中；公共 schema 没有额外 role 字段 |
| 生活方式、日常计划 | scratch.lifestyle、daily_plan | 计划已经统一两日日期、讨论/答疑地点、提前出发、迟到处理 |
| 当前目标/状态 | currently | 简短当下状态；不拿它替代完整人设输入 |
| 长程目标 | goals | 已去掉 ACT/WAIT/可回放等技术措辞，改成生活目标 |
| 视野、注意力 | perception.vision_radius、attention_bandwidth | 前三人10/12，王建国12/14 |
| 行走图布局 | sprite_layout=4x3 | 图片3列4行，系统名称4x3；不要选早期4x4资源 |

头像与行走图使用姓名目录下 `portrait.png`、`texture.png`。旧根目录的模糊素材不上传。四个人初始地点、常用地址和已知空间需要在实验草稿配置，依据校准后的地图；旧 txt 的数值不能直接用。

`studio-definition.json` 是本次修订后的完整字段底稿，优先于旧 `agent-definition.txt` 中被标注需要修订的日程和技术目标。没有改动现有管理台中的四个公共 Agent。
