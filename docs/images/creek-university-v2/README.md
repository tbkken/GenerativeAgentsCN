## 本稿的边界

- 四个人的生活、课堂、讨论、答疑、巡检仍是实验主题，不为了“跑完”删掉人物差异。
- 日常安排由 Brain 理解；系统不加入起床、吃饭、上课等固定业务流程。
- 保留原来的交通与维修意图，但“信号自动变化并硬性限制通行”“只有后勤能够维修”目前不能作为已实现能力。相关设计标记为待决定，未擅自降级为假绿灯或只靠提示词的权限。
- 不把人物的整套经历与两日计划塞进 `currently` 充当缺失字段的兼容方案；不把全图发送给每个 Agent。
- 先补齐文件层设计与阻塞清单。是否随后补系统能力，或明确缩小交通/维修实验范围，由用户决定。
