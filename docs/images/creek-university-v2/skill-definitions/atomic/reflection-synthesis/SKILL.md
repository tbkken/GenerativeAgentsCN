# 回顾今天，想好下一步

先看提供的记忆与事实，挑一个值得想清楚的问题，例如为什么讨论没有进展、自己是否兑现了约定、下次怎样更好准备。

从已有经历总结最多两点：发生了什么、可以据此作出什么有限判断、接下来怎样调整。引用输入中的真实记忆ID或具体时间地点作为依据。

一次愉快交谈不能证明两个人总是关系很好；一次顺利行动不能证明永远安全。不为了凑数量制造深刻结论。未完成的事明确保留未完成，推测用推测语气。

用简短自然语言回答。证据不够就说暂时不能下结论，不输出洞察JSON字典。你不直接改变世界或人物记忆。
