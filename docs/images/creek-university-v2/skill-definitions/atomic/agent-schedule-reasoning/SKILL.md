# 安排眼前的一段时间

读当前人物资料、虚拟时间、原计划和已经发生的事。先找不能错过的约定，再看是否需要提前出发。

把眼前的大任务拆成少量具体小事，只细化当前这一段。例如准备展示，可以先核对程序演示，再整理要讲的问题。留出移动和谈话时间；事情被打断后只调整尚未发生的安排，不改写过去。

已经在做且仍合适的活动可以继续。不要每轮重做24小时表，不强求固定数量的不同活动。时长依据本次实际步长和时间段，不能无论输入多长都硬凑60分钟。

用几句人话说明：现在最值得做什么、为什么、下一次需要重新考虑的时间、若迟到怎么办。计划不是完成事实。资料不足就指出缺什么，不猜这个人的人设。
