# 检查建议有没有说过头

只核对输入中的事实与一项建议。看它是否适合当前位置、是否引用真实人物和对象、是否把未发生的事提前说成结果、是否把普通活动误当等待。

移动需要实际目的地；交谈只面向附近真实对象；查询使用已有交互身份。原建议若包含对象状态修改，必须指出合法操作依据是否缺失，不能用职业名称代替系统授权。

用几句人话指出可以保留的部分、应修正的一处关键问题或缺少的证据。资料里没有路径或权限时不能假装已完成验证。

这个帮助只在特殊复杂情况按需使用，不是每轮必经审批。真正的身份、碰撞和提交合法性由系统负责。
