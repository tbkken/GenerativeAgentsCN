## 已存在、可以据此写 Skill 的能力

代码路径在 `generative_agents/` 下：

| 能力 | 依据 | 对设计的约束 |
| --- | --- | --- |
| 工具暴露 | `skills/runtime.py:_run`，工具名需出现在 Markdown；world-act 仅根调用可见 | 保留精确 MCP 名字；子 Skill 用自然语言帮助判断，不承担提交 |
| 自然语言子调用 | 同上，call_skill 接收 name/input_text，工具说明明确 natural-language result | 不要求子 Skill 输出另一个机器 JSON 合同 |
| 根动作后终止 | `skills/runtime.py` 根层成功 world-act 后直接返回；`runtime/brain.py` 同一轮无动作记录 missing_action | “动作后再记忆/再反思”不会按原想法执行；重要上一轮事实在本轮动作前保存 |
| 感知 | `runtime/capabilities.py:tools/_perceive` | 半径参数叫 radius_tiles；身份由运行绑定。对象与交互是嵌套结构，不猜 selection_key |
| 移动与普通活动 | `runtime/capabilities.py:_resolve_path/_plan_action`，`modules/game.py:commit_world_action` | MOVE 需要 target_address 或 target_coord；单独 target_node_id 不够。ACT 是当前地点事件，不能用文字假装远程活动 |
| 移动消耗 | `start.py:_movement_budget`，`config/algorithm.py`，`modules/game.py` | 路径每步最多消费 stride×4 格；剩余路径不是已经到达。下一轮重新判断并继续朝同一目标移动 |
| 对话 | `runtime/capabilities.py:_participant_keys`，`modules/game.py:record_conversation_message` | 每轮一个附近对象；同一会话复用真实 ID；三人讨论通过多轮一对一发言呈现 |
| 对象反馈 | `modules/game_object_interaction.py:interact_selected`，`modules/game.py` 的 INTERACT 分支 | 输入有 step_no/virtual_time/agent/game_object/object_state；响应排入请求者的 external_observations。不是完整人物配置 |
| 独立实验与 Run | `ga_studio/workspace.py`，`ga_studio/builder.py`，`ga_runtime/executor.py`，`ga_replay/reader.py` | 选入实验就物理复制；修改公共 Skill 不会自动修正旧草稿/封存包/Run |
