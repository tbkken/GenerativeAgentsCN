## 新发现的鉴权衔接风险

探针可以在内存中用缓存凭据鉴权，但管理台启动 Run 的路径不等于探针路径。`ga_studio/builder.py` 会把 Studio secret_ref 转成 credential_env（如 GA_CHAT_API_KEY）；`ga_runtime/package.py` 只从环境读该值；`ga_runtime/supervisor.py` 启动子进程时没有看到从 Studio 密钥或本地缓存向子进程注入凭据的桥接。

本次探针进程的 GA_CHAT_API_KEY 没有设置。不能由此断言已经运行的管理台进程也没有该环境变量，因此列为**待核实的 Run 启动阻塞**，不谎报已经实跑出401。当前服务明确要求鉴权，这条衔接必须在声称“通过页面可完整运行”之前核实。本次未修改任何环境变量或密钥配置。
