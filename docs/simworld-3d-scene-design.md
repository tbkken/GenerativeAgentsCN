# SimWorld 在线集成

SimWorld 管理三维世界：场景目录、UE 关卡及依赖、角色和设施、运动与碰撞。GenerativeAgentsCN 管理实验、Brain、Skill、仿真步和已提交事实。服务 URL 和凭据配置在运行主机，不写入实验或 Run。

| 操作 | 本项目保存 | 外部服务负责 |
| --- | --- | --- |
| 选图、换图、封存 | 实验资源中仅 `environment_type: spatial_3d` 和 `simworld_scene_id`；作者的 Agent、Brain 和 Skill 仍是包内副本 | 注册、加载和保管场景；登记新场景后才会出现在目录 |
| 在线查看 | 无截图、视频、机位或场景缓存；观察不提交世界变化 | 场景 ID 会话、真实相机、实时画面和释放 |
| 智能体执行 | Run/Attempt/Step/Agent 身份，已提交的实际位置、轨迹、动作、对话、对象结果与恢复检查点 | 分配真实出生位置，在线感知、移动及设施操作，按同一 Run/Step/参与者辨认重复请求 |
| 恢复与回放 | 文件中恢复同一 Run，只重放已提交事实；新 Attempt 不改变外部动作的逻辑身份 | 保留对应的远端世界及动作结果。UE 实景必须使用该服务；失联、关卡不可用或不能确认已执行动作时，不能把猜测写成成功 |

自建关卡由 SimWorld 管理员在服务主机的 `GA_SIMWORLD_SCENE_DIR` 目录通过 `scenes.json` 登记。登记信息包括场景 ID、显示名、UE 关卡 URI 和依赖 PAK 摘要。服务重启后，本项目的在线目录会列出通过校验的场景。登记文件、素材和校验均由服务负责。

获取场景目录、查看 UE 画面和执行仿真是不同能力。已安装关卡可尝试打开；某张地图能否安全出生、移动或与特定设施交互，要看服务和该实体实际支持的能力。不会因场景缺少资料而虚构地图坐标、扩大可走范围或回退本地几何。若服务只支持预览，UI 可观看地图，但不能用一次相机漫游证明智能体已行动。

`.gaexp` 和 `.garun` 不含 SimWorld 提供的 PAK、模型、地图几何、截图或原始响应。仅凭包可以核对本项目的事件、时间线和对话，不能离线恢复已删除的远端场景外观。1D/2D 的包内资源、运行及回放规则不变。

在线导航当前验证最多 16 米的直达路线。复杂绕障、跨楼层和任意设施状态切换取决于服务的具体实现，接口拒绝时保留原因。提供方识别出的受支持设施可确认实际接触；回放只显示已提交的动作和经过核验的状态变化。

## 在线集成验收

2026 年 11 月 4 日，Studio 从在线目录打开 QA Modular Parking 的真实 UE 画面。在 Tokyo 新建的实验 `d7472f5a-067c-4240-b577-b24e90523902` 只保存 `map-15`。Run `beeb6ff4-bc94-4a3c-95fe-ce44f6958ccd` 完成 1/1 步。周浩洋的已提交移动有 19 个实测路径点，从 `[-46.8, -9.8, 0.4015]` 移到 `[-43.06245, -8.52062, 0.30149]`。在 Studio 和远端服务重启后，打开同一 Run 仍收到 Step 1 的 UE 人物画面。该 Run 的唯一质量观察项是首次记忆检索为空。实验内两张 PNG 属于 Agent 的头像和行走图，地图附件清单为空。

恢复实机验收使用独立服务目录和临时实验。Tokyo 的角色请求移动 1.2 米，实际水平位移约 1.164 米。服务断线时停在 Step 1。将暂停的 Run 封存并解到新目录后，提供方从既有动作记录恢复，同一 Run 的新 Attempt 提交 Step 2。GPU 主机可用 `GA_TEST_UE_EXE` 和 `GA_TEST_SIMWORLD_PAK_DIR` 重做这一验收。[实机验收测试](../tests/runtime/test_simworld_ue_integration.py)

## 历史：Tokyo 快照样板

以下为此前使用内嵌地图文件的历史记录，保留原始实验与 Run 的证据；其导入、打包步骤不适用于在线集成。

2026-11-02，首个样板选用官方 **Tokyo Stylized Environment**。通过新建实验向导选图后，在草稿的「当前实验 → 地图」看到了连续 UE 街景，切换到「樱花街口」并实际操作相机。封存后，同一实验在原图库不可用、缓存为空的隔离渲染实例上重新打开。从包内传入原厂地图 PAK 和材质依赖 PAK 后，UE 再次显示人行道，能够切换到樱花街口。主机需安装匹配的 SimWorld Base 运行环境。整个过程产生零个 Run。

本次实验 ID 为 `ad54fe15-ac30-4b5b-94dd-f1117e7aecc9`，归档大小 165,462,554 字节，文件 SHA256 为 `f5041db97b8de73feae587065803d3b97b233dc8f314b2a587b1a4c4b71b687c`。可用导航数据覆盖已实走核对的 10 米人行道、两个出生点、一个灯柱旁站位。UE 相机可以观看周边城区。下一阶段用两名形象可区分的 Agent 核验会合、设施交互与回放，下表是完整验收设计。

同一封存实验也完成了新版查看器复验：在 1341 × 884 的浏览器窗口中，1280 × 720 的 UE 原生画面等比显示为 1125 × 633，铺满侧栏以外的宽度。点击「人行道」「樱花街口」「由里 · 街区观察员」能依次看到不同的街景。由里的镜头位于护栏内侧、靠近树篱；点击「返回自由视角」后重新看到之前路口的自行车与樱花树。全屏模式仍能选择机位，整个复验未启动 Run。

两个入口共用查看器后的复验也使用了这张地图。「基础配置 → 地图 → Tokyo Stylized Environment」收到同样的 1280 × 720 实帧，能直接切到「樱花街口」，全屏中返回公共列表后可以再次打开。公共地图只列地图机位；封存实验另列「由里 · 街区观察员」，实测可切到角色眼位。公共列表里的旧「槐荫路口」没有保存 UE 关卡，打开后明确说明不可预览，并提供返回列表和从 SimWorld 选图的入口。

2026-11-03，已补齐周浩洋与由里角色包的实验 `40576851-45ed-49a7-8f9f-de21f2dd68a7` 完成 30 步，Run 为 `5339bdff-e3a0-477c-9f96-1461029faa6b`，Attempt 为 `cf3cc44f-7e8c-45f8-a5f3-569196dc92b4`。浏览器从固定机位连续播放并核对了全部 30 个 UE 终点帧。首步中两人从人行道两侧走向同一路灯，抵达同一坐标。暂停在第 11 步时，周浩洋的位置为 `[-46.8, -4.3, 0.4]`，由里为 `[-46.8, -3.04597, 0.4]`。倒回第 1 步后两人均回到 `[-46.8, -3.04597, 0.4]`。骑车、观察和整理笔记等具体活动以本步记录为准，人物形象提供待机、转身和行走动画。

2026-11-03 的同 Run 对照在 `5339bdff-e3a0-477c-9f96-1461029faa6b` 以 1× 播放、各采样 15 秒。页面观察到的新图像从 2.2 张/秒增至 13.0 张/秒，步切换间隔从 1.15–1.37 秒降至 0.06–0.20 秒。在第 1 步跟随周浩洋，最终机位保留了人物全身、护栏和街道。

**UE 人物四肢拉伸的复现与定位。** 在实验 `4dc5ca4a-8187-4a65-960b-0dbc25106387` 的回放中，打开 Run `a65f000a-1847-445e-85f7-e3f6d62c3f89`、Attempt `dc028cdd-e112-49d2-8dd4-683a4587d1f2`，跳至第 2 步并全屏。周浩洋与由里的前臂和小腿明显拉长，编辑器里的同一份 GLB 则保持正常人体比例。这个封存 Run 保留了两份有问题的 PAK。

UE 5.3.2 的 glTF 导入器在骨盆根关节没有父节点时，将骨盆变换再次应用到已处于绑定位置的网格。两人的网格分别比骨架高出 93.03 和 88.84 厘米。SimWorld 0.1.4 构建 PAK 时，在临时 GLB 中给顶层关节加上单位变换父节点。以原始 GLB 为基准，用 UE 实际导出的顶点、权重和压缩动画在行走周期的四个相位复测。修复后，周浩洋与由里裤腿顶点位置误差的 99 分位分别在 0.85 和 0.81 厘米以内。原始素材摘要仍可用来核对封存实验中的人物来源。

**实景复验通过。** 独立实验 `fdde567b-c322-4c5e-99b9-5b5280d66ca9` 在 Studio 中分别重新构建并采用两人的 PAK。Run `051bb62c-b392-4de5-b444-e10cfe221f69`、Attempt `8d7b5e00-6cc1-4454-84b8-d93e8844d2c5` 完成 6/6 步。浏览器中分别跟随两人，慢放首步相向移动，查看站立和迈步时的前臂、小腿与脚底。第 2 步两人同在 `[-46.8, -3.04597, 0.4]`，模型重叠。第 5 步由里留在灯旁，周浩洋走到 `[-46.8, -9.8, 0.4]`，人物全景可分辨黄色头盔和青色上衣。1× 实播从第 1 步的路径帧到第 6 步的终点帧耗时 9.36 秒，浏览器观察到 186 张新画面，五次步切换间隔为 90–146 毫秒。

2026-11-03 21:33（Asia/Shanghai）生成的最终结果 ZIP 为 177,566,633 字节，SHA256 为 `b1e6fa4c463ba951a9f47bcc5c93666ccd2d30d68e946b1d0a18bb0cdfa82b49`。归档已核对全部六帧、两人 GLB、PAK 和清单的字节摘要，质量报告的 20 项观察与页面一致。由里第 6 步模型调用超时回退为等待，回放保留该动作。

| 顺序 | 操作 | 通过条件与留证 |

| 6. 离线自由回放 | 将最终 `.garun` 移到没有 UE、无法访问 3D 服务和公共素材库的机器。选取会合前、交互时、回复后三个已提交 Step | 能自由转动视角、点选两人和长椅，核对姿态、轨迹、消息与对象状态。记录 Run、Attempt、Step、原包 SHA256、质量明细和对应回放画面 |

实施时优先验证小型街区能否离开原素材库加载，以及两名 Agent 能否凭现有图片生成在浏览器与 UE 中都可辨认、可行走的角色。随后用同一街区完成断线、恢复和离线回放验收，再扩充城市规模与素材品类。
