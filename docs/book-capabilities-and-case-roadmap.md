# 教材能力与案例总纲入口

书稿总纲已统一到 [系统原理与使用：能力盘点及递进案例方案](book/book-capabilities-and-case-roadmap.md)。能力顺序、案例规模、出版准入和当前边界均以该文件为准，本入口不再维护第二套路线。

相较于早期“校园活动室”草案，现行方案保留“先完成实验，再解释原理”的讲解方式，并作了以下调整：

- 案例 1 改为陈明远的连续晨间生活，以完整住宅背景、真实移动、最小私人进度便签和桌面状态变化建立可观察的生活闭环。
- 每个案例自备地图、人物、Skill 和设置文件，方便独立复现；后续案例逐步深入移动边界、记忆证据、物品反馈及多人协作。
- 运行控制单列微案例，文件协议、离线回放及专项边界验收放入附录；源码存在、页面保存与完整实验通过分别记录。

案例 1 的实际配置入口为 [浏览器作者清单](book/sample/01-morning-routine/settings/browser-authoring-checklist.md)，当前进度见 [验证记录](book/sample/01-morning-routine/settings/verification-record.md)。旧现场 Run 的临时进度不作为教材能力结论。
