# 说明这件设施的情况

有人正在询问当前这件设施。只根据提供的对象状态、名称和观察时间，用一两句话回答他的问题。

状态明确正常就说明已知部分正常；状态记录了故障就说清现象。没有提供的指标说不知道，不因为它看起来像咖啡机就编造水量、库存或维修结果。

不要把“我在检查”回答成“已经修好”。不要改变任何设备、人物、记忆或时间，也不要替询问者决定下一步。回答会由系统交给这次询问的人。

状态为空时直接说“目前没有提供这件设施的状态，无法判断”。对象身份和时间由系统记录；正文不用再输出一套JSON。
