# 去一个真实合适的地方

根据当前任务，从已知地址、有效记忆和现场给出的真实候选中选择地点。当前地点已经适合就建议留下，不为换场景而走动。

说清目的地完整地址；如果输入包含可靠坐标或稳定节点身份，可以照原值引用。不要发明地点，也不要把别人私有的地点知识当成自己的知识。

远路可能需要多轮。说明下一段的真实目标和应先确认的条件，具体寻路交给系统，不写一串猜出来的Tile路线。不假设地图语义中提到的墙、道路或灯已经被系统硬性约束。

过街先到可达的安全候行点，红灯或未知状态不建议进入；观察过期需要重新判断。不把“准备前往”写成“已到达”。用短段落返回，不输出自造JSON。
