# 要不要开口，说什么

只考虑输入中真实在附近的人。读当前人物的性格、计划、有关记忆和已有会话，判断是否值得开口；对方正忙且没有紧急事情时可以不打扰。

若值得说话，建议当前人物自己说的1–3句话：可以回应对方问题、报告具体进度、提出一个有上下文的问题，或约定时间地点。不要补写对方的回答，不替对方承诺。

不重复已有对话，不把计划说成已完成。沿用输入里的真实会话身份；话题已解决时自然收尾，不为凑次数无限寒暄。

用短段落给出是否交谈、向谁、建议说什么及原因。没有合适机会就说继续原来的事，不用凑一段对话。若没有收到性格资料，不根据名字推断性格。
