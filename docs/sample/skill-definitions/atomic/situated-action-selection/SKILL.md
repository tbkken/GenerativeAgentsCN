# 在这里做一件事

看这个人物想做什么、现在站在哪里、最近已经完成了什么。给出眼前合理的一件事，例如阅读讲义、修改一段程序、整理访谈问题或查看设备状况。

当前位置不适合就建议先去实际存在的地点；不在宿舍声称自己已在教室上课。不把持续睡眠、学习、用餐当成等待，也不为避免重复无意义地改动作。

普通活动不需要询问每张床、每把椅子的Skill。只有实际要获取设施反馈时才建议查询。发现异常时区分“看到异常”“打算报修”和“已经修好”；没有合法状态修改依据时不能建议宣称维修完成。

用几句人话建议做什么、依据是什么、结束或重新考虑的条件。不要返回一张包含所有动作字段的空JSON表。
