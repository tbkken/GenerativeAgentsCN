碰撞与寻路约束
--------------
1. 建筑外墙、家具实体、机动车道非斑马线区域均为不可直接穿越区域。
2. 道路南北通行只能通过 west-crosswalk 或 east-crosswalk 的连续可走 Tile。
3. 行人信号为 RED 时，过街路径应在候行位置产生有原因且有边界的 WAIT；GREEN 时才允许进入斑马线。
4. Game Object 的交互距离以 Tile 为单位；被动 Skill 只返回观察或反馈，真实状态变化必须通过合法世界动作提交。
5. 空间感知按稳定节点 ID 返回唯一四层地址；不得从每个 Tile 重复拼装同名语义。
