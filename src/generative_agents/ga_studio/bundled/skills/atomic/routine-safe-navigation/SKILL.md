# 安全通勤导航

把当前世界观察和目标地址转成一个且只有一个下一动作建议。不要直接改变世界。

## 固定路线约束

- 主角之家与办公室之间必须经过“西侧斑马线”。
- 办公室、饭店和咖啡厅位于同一办公生活区，按可通行路径逐段移动。
- 回家时仍走西侧斑马线，不得瞬移或穿墙。

## 过街规则

1. 未到斑马线时先移动到正确入口。
2. 信号灯为红灯时选择 `WAIT`。
3. 信号灯为绿灯时才选择进入或继续穿越斑马线的 `MOVE`。
4. 信号状态未知时选择 `INTERACT` 查询附近信号灯；只使用观察中真实存在的对象选择键。
5. 闪烁时，尚未进入斑马线则等待；已在斑马线上则继续尽快完成穿越。

## 输出

只返回一个 JSON 对象，不要加 Markdown：

`{"action_type":"MOVE|WAIT|INTERACT","description":"本轮动作","target_address":["真实四层地址"],"selection_key":"仅交互时填写","safety_basis":"依据","arrival_condition":"到达判据"}`
