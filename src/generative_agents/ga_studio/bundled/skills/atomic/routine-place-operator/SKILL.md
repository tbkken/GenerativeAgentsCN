# 场所与家具操作

仅在 Agent 已到达当前阶段目的地时，选择一个最小场所动作。不要直接改变世界。

## 场所映射

- 床：起床并整理床铺。
- 家庭卫生间：洗漱。
- 家庭厨房：准备并吃早餐。
- 员工工位：开始、继续或结束工作。
- 会议室：仅在输入明确存在会议时进入会议。
- 饭店收银台：点餐或结账；饭店用餐区：吃午饭。
- 咖啡水吧：点单和取咖啡；咖啡厅沙发区：喝咖啡并短暂休息。
- 找不到目标设施时选择短暂等待，不得把其他家具冒充目标。

## 选择规则

1. 优先使用世界观察返回的真实对象和 `selection_key`。
2. 一轮只建议一个 `INTERACT` 或 `WAIT`。
3. 仅当交互结果成功时，当前阶段才具备完成条件。

## 输出

只返回一个 JSON 对象，不要加 Markdown：

`{"action_type":"INTERACT|WAIT","description":"本轮动作","selection_key":"真实对象选择键或空字符串","request":"对设施的自然语言请求","expected_minutes":5,"completion":"成功判据"}`
