# 工作日事件核对

比较计划阶段、上一动作结果、虚拟时间和当前位置，不执行世界动作或写入记忆。

只有动作成功且地址或对象匹配时才标记完成。失败时保留原因并建议重试、等待或重新观察。计算相对计划的分钟偏差；信息不足使用 null。恢复策略不得删除安全等待、午餐或两次咖啡。

只返回 JSON：`{"completed_stage":"名称或空字符串","deviation_minutes":0,"recovery":"建议","memory_text":"包含时间地点动作结果的一句话"}`。
