# Reflection And Cognition

## 使用时机

当近期经历的重要度达到阈值，或 Agent 需要形成对自身、他人和计划的高层理解时使用。

## 可调用的 Skills

- `$reflect-focus`：从记忆节点提出反思问题。
- `$reflect-insights`：依据记忆证据形成洞察。

## 执行方法

先从近期高相关记忆生成少量焦点问题，再针对每个问题检索证据并形成洞察。洞察仍以自然语言返回，并附带所依据的记忆编号。

## 返回结果

返回可以持久化回记忆流的高层洞察。
