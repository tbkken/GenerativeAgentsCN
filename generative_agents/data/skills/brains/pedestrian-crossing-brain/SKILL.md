# Pedestrian Crossing Brain

## 实验目标

让 Agent 在同一条连续时间线上完成一段有起点、过程、风险点和终点的晨间故事，而不是只做一次过街动作。

故事主线：

1. 07:00 在“床与闹钟”醒来、关闭闹钟并整理床铺；
2. 前往“盥洗台”洗漱；
3. 在“早餐桌”吃早餐、喝水并确认上午安排；
4. 收拾随身物品，从“公寓出口”离开住宅；
5. 沿北街区步行到中央大道；
6. 进入西侧人行横道的北侧等候区；
7. 主动查询附近信号灯的被动 Skill，并把返回的自然语言当作外部观察；
8. 依据信号等待、进入或继续通过斑马线；
9. 到达南侧出口后继续步行；
10. 从“公司入口”进入创意园；
11. 到达“林晓的办公工位”，整理桌面、查看邮件；
12. 09:00 前后开始当天上午的工作。

## 地图事实

始终以发布地图的四层地址和可通行网格为准：

- 起点：Ville 清晨起床到上班世界 → 林晓公寓与北街区 → 晨间起居与出门区 → 床与闹钟
- 过街：Ville 清晨起床到上班世界 → 中央大道与人行横道 → 西侧人行横道 → 北侧等候区 / 信号灯 / 南侧出口
- 终点：Ville 清晨起床到上班世界 → 创意园公司街区 → 创意园公司办公区 → 林晓的办公工位

不凭空创造地图上不存在的第五层地址，不把素材名称当成新的空间层级。

## 可调用的 Skill Packs

- `$daily-planning`：在实验开始时建立 07:00—09:00 的阶段计划；延误时只修订后续时间，不删除安全步骤。
- `$perception-and-memory`：记录当前四层地址、已完成的晨间事项、信号观察和等待经历。
- `$action-and-space`：在同一 Arena 内选择对象，在父子地址之间推进，并沿可通行 Tile 逐步移动。
- `$reflection-and-cognition`：在完成过街或抵达工位后，总结安全策略与通勤结果。

## 每一步的决策顺序

1. 读取当前虚拟时间、四层地址、正在执行的故事阶段和未完成目标。
2. 若当前阶段尚未完成，优先完成同一地点内的自然动作，不跳到后续地点。
3. 需要换地点时，通过 `$action-and-space` 选择地图中真实存在的下一地址并沿路径移动，禁止瞬移。
4. 只有附近出现可用信号灯交互且当前阶段确实需要过街时，才通过 `$decide-game-object-interaction` 主动查询。
5. 把 Game Object 返回的自然语言交给 `$decide-game-object-response`：
   - 红灯：留在等候区，并在后续世界步再次观察；
   - 绿灯：进入斑马线并持续向南通过；
   - 闪烁：已进入者尽快完成通过，尚未进入者继续等待。
6. 过街后恢复“到公司上班”主目标，不在信号灯附近循环。
7. 到达工位后执行整理桌面、查看邮件、开始工作，形成可辨识的故事结尾。

## 时间与行为约束

- 以 07:00 为开始时间，至少覆盖 120 分钟虚拟时间。
- 起床、洗漱、早餐、出门、步行、等灯、过街、进公司、到工位和开始工作都应在状态记录中出现。
- 行程延误时可以压缩早餐或整理桌面的时长，但不能省略安全过街判断。
- 不猜测未查询的信号相位，不因信号灯进入感知范围就自动运行其 Skill。
- Game Object 只提供自然语言观察，不替 Agent 修改计划、坐标或记忆。
- 每个世界步只返回一个可执行的下一行动，并保持与上一阶段连续。

## 返回结果

返回当前世界步可直接执行的一个行动，同时指出：当前阶段、目标四层地址、为什么现在做这件事，以及完成后将进入哪个下一阶段。
