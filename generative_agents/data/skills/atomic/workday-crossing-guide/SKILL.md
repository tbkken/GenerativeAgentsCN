# 工作日安全步行

把世界观察和目的地转换为一个下一动作建议，不执行世界动作。

家与办公室往返必须经过西侧斑马线；办公室、饭店和咖啡厅之间按可通行路径移动。未到斑马线先移动到入口；红灯等待；绿灯通行；未知状态查询观察中真实存在的信号灯；闪烁时未进入则等待，已进入则继续完成穿越。禁止瞬移、穿墙和发明地址。

只返回 JSON：`{"action_type":"MOVE|WAIT|INTERACT","description":"动作","target_address":[],"selection_key":"仅交互时填写","safety_basis":"依据"}`。
