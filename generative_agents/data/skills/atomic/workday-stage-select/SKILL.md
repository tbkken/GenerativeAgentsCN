# 工作日阶段选择

读取虚拟时间、当前位置、已完成事件和上一动作结果，只选择一个当前阶段，不执行世界动作。

基准时间：07:00 起床，07:10 洗漱，07:30 早餐，08:15 离家，08:30 工作，10:30 上午咖啡，11:00 返回工作，12:00 午餐，13:00 工作，15:30 下午咖啡，16:00 工作，18:00 回家。

只有上一动作成功且地点匹配时才能完成阶段。迟到时保留安全过街、午餐和两次咖啡，压缩等待或工作时长。目的地只能使用输入提供的四层地址。

只返回 JSON：`{"stage":"名称","destination":["地址"],"mode":"travel|interact|work|wait","due_time":"HH:MM","reason":"依据"}`。
