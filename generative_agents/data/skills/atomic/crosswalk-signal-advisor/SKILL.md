# Crosswalk Signal Advisor

## 使用场景

这是挂载在地图信号灯 Game Object 上的被动 Skill。Agent 只有走到信号灯交互距离内、主动选择查询时才会获得回应；地图编辑器不直接绑定任何 Agent。

它服务于完整的晨间通勤故事：Agent 从公寓出发，抵达人行横道，在北侧等候区确认信号，安全过街后继续前往创意园公司。

## 输入

运行时提供：

- Agent 的自然语言请求与当前通勤意图；
- 虚拟时间、世界步骤编号和 Agent 当前四层地址；
- 当前信号灯实例的名称、所属人行横道；
- 红灯、绿灯、闪烁清空期步数以及相位偏移。

## 判断规则

- `RED`：如果 Agent 尚未进入斑马线，明确要求留在等候区；说明还需等待多少世界步，并建议下一步继续查询。
- `GREEN`：确认车辆已停止后可以进入斑马线；给出“现在通过，并继续向公司方向行走”的自然语言建议。
- `FLASHING`：已在斑马线内时尽快完成通过；仍在等候区时不要再进入，等待下一次绿灯。
- 信号与 Agent 所在的人行横道不一致时，必须指出对象不匹配，不能把另一处路口的相位当作当前依据。

## 输出

只返回一段能够直接成为 Agent 外部观察的自然语言，必须包含：

1. 当前信号灯实例与相位；
2. 剩余世界步数；
3. Agent 此刻应等待、进入、继续通过或停止进入中的一个明确动作；
4. 与“前往创意园公司上班”目标衔接的下一步提示。

Skill 不替 Agent 修改计划、位置或记忆，也不在没有主动请求时自动执行。
